## 5 分钟先跑起来（不装 DevEco 也行）

只需要 **Python 3.8+**（网关只用标准库，不用 pip 装任何东西）。

```powershell
# 1) 解压后进入 software 目录，配置本机路径（一次性，写用户环境变量）
powershell -ExecutionPolicy Bypass -File scripts\setup_paths.ps1

# 2) 自检：Python / 端口 / 模拟器 / HAP 四样
powershell -ExecutionPolicy Bypass -File scripts\sim_preflight.ps1

# 3) 跑网关的 86 项单元测试（确认代码没坏）
python -m unittest discover -s tests -q          # 期望：Ran 86 tests ... OK

# 4) 起网关 + Web 看板 + 模拟设备
powershell -ExecutionPolicy Bypass -File scripts\demo.ps1 -Siren -Voice
```

浏览器打开 `http://127.0.0.1:8780/` 就是看板；另开窗口注入场景：

```powershell
python sim\incident.py --type temp     # 温度偏高 → L1
python sim\incident.py --type sos      # 随身求助 → L3（网关带 --voice 时会播报「我需要帮助」）
python sim\incident.py --type smoke    # 烟雾（火灾监测）→ L3
python sim\incident.py --type gas      # 燃气泄漏 → L3
python sim\incident.py --type reset    # 复位
```

> 语音：`demo.ps1 -Voice` 默认用系统 TTS 代播；接上 BY8301 语音模块后改 `python run_gateway.py --voice --voice-backend serial --voice-port COM3`。

**只想看软件长什么样**：装个鸿蒙模拟器，把我们预置的 HAP 装上即可（不需要编译）：

```powershell
# DevEco Studio → Device Manager → Local Emulator → Mate 90 Pro → Start
& "<DevEco安装目录>\sdk\default\openharmony\toolchains\hdc.exe" list targets   # 期望 127.0.0.1:5555
& "<DevEco安装目录>\sdk\default\openharmony\toolchains\hdc.exe" install -r dist\entry-default-unsigned.hap
```

APP 里「我的」→ 网关地址填 `http://127.0.0.1:8780` → 保存并测试连接。

## 三条硬规矩（会直接影响成绩，别踩）

1. **禁词**：不得出现体态医学结论类用词（具体词表见 `scripts\check_words.py` 的 `FORBIDDEN`，脚本用 chr() 组装避免自我命中）。`python scripts\check_words.py` 会扫，当前 0 命中。
2. **数据不造假**：没有的传感器写 `null`；模拟数据 `source` 必须是 `test`，真实板子才是 `hardware`。APP 会显式标注来源。
3. **契约以 `docs/hardware-contract.md` 为准**：改字段名要同步网关/APP/模拟器/文档，先沟通再动。

## 常见坑（先看，省两小时）

| 现象 | 原因 |
|---|---|
| `python sim\incident.py` 报 can't open file | 没在 `software` 目录下执行；用 `scripts\incident.ps1 -Type temp` 不受目录影响 |
| 脚本报路径不存在 | 没跑 `scripts\setup_paths.ps1`，脚本还在找开发机路径 |
| APP 连不上网关 | 模拟器场景地址必须是 `http://127.0.0.1:8780`，不是局域网 IP |
| 注入后 3 秒没动静 | 网关刚启动 180 秒内不判“无活动/门未关”这类累积型告警（预热期） |
| 改了 APP 代码但构建出来还是旧的 | 老问题：`build_app.ps1` 现在会自动同步源码，仍不行就手动跑 `scripts\sync_app.ps1` |
| 端口 8780 被占 | `scripts\demo.ps1 -Stop` 或 `-Port 8790` |
