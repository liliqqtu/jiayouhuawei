## 二、必须人工实测的点（评委现场会看）

| # | 场景 | 判定标准 | 常见失败 |
|---|---|---|---|
| M1 | 真实 PIR 触发 | 串口 `pir=1` 且 APP 3 秒内更新 | Wi-Fi 未连、网关 IP 写错 |
| M2 | 无活动告警 | 板端 LED 闪 + APP 出现“疑似长时间无活动” | 阈值太大、`lastMotionTs` 未刷新 |
| M3 | 求助优先级 | 按求助后，环境告警不得覆盖它 | 板端 `alarm_active` 未判断类型 |
| M4 | 传感器缺失 | 温湿度/光照显示“—”，**不是 0** | 固件写了默认值 |
| M5 | 来源标注 | 按键/模拟数据必须显示“测试/模拟” | `source` 被写成 `hardware` |
| M6 | 断网继续工作 | 拔网线后 LED 仍闪、串口仍有 `#JSON#` | `SensorTask` 里调了网络 |
| M7 | 离线看历史 | 关网关后 APP 仍能看到已关闭告警 | 本地库没初始化 |
| M8 | 重启不丢 | APP 杀进程重开，台账仍在 | RDB 未 flush |
| M9 | 串口桥接降级 | `--serial COM3` 启动后 APP 仍有数据 | 串口被占用、波特率不对 |
| M10 | 措辞合规 | 全链路无医学禁词 | 文案/注释残留 |
| M11 | 断网本地判定 | 关掉网关后捂热传感器/开门，LED 仍按等级闪、串口有 `[local]` 日志 | 本地判定没接进采集任务 |
| M12 | 下行停响 | APP 确认后板端 10 秒内停响、LED 常亮 | ACK 轮询没跑 / deviceId 写错 |
| M13 | 看板可用 | 手机浏览器打开 `http://电脑IP:8780/` 能看到当前状态 | 防火墙拦了 8780 / 用了 127.0.0.1 |

## 三、演示前 10 分钟检查

1. 网关 `--lan` 已启动，防火墙放行 8780
2. 板子串口有 `sntp synced` 与 `#JSON#`
3. APP「我的」连接测试通过
4. `curl /api/v1/device` 返回 `online: true`
5. 现场触发一次 L2，确认声光与 APP 同步
6. 检查桌面/文档里没有校名、姓名（提交材料匿名要求）
