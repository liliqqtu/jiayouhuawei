# 队友复现指南：在自己电脑上跑通软件 → 硬件完成后回归验收

> 面向：拿到 `守夜灯_软件包_*.zip`、此前**没有这份代码**的队友。
> 目标：第 1 部分结束时你能在模拟器里把 APP 跑起来并看到告警；第 2 部分是板上线后的回归清单。
> 全程不需要联网装 pip 包（网关是 Python 标准库），也不需要华为账号（模拟器装未签名 HAP 是允许的）。

---

# 第 0 部分 · 装机清单（15 分钟）

| 要装 | 版本 | 用途 | 备注 |
|---|---|---|---|
| Python | 3.8 及以上 | 跑网关、模拟设备、测试 | 安装时勾选 “Add to PATH” |
| DevEco Studio | 26 或更新（HarmonyOS SDK） | 起模拟器、装 HAP | 只跑软件也要它来提供模拟器与 `hdc` |
| 解压工具 | 任意 | 解包 | — |

> 只要硬件联调、不看 APP：**可以跳过 DevEco**，第 1 部分的 1.3–1.6 节跳过即可。

装完先确认：

```powershell
python --version        # 期望 Python 3.8.x 或更高
```

# 第 1 部分 · 在自己电脑上把软件跑起来

## 1.1 解压 + 配置本机路径

解压后进入 `software` 目录（**以后所有命令都在这个目录下执行**）：

```powershell
cd <你解压的位置>\守夜灯_软件包
powershell -ExecutionPolicy Bypass -File scripts\setup_paths.ps1
```

它会自动找 DevEco Studio、Python，把路径写进用户环境变量（`SHADOWLAMP_STUDIO` / `SHADOWLAMP_PY` / `SHADOWLAMP_PROJECT`）。
如果找错了，可以手动指定：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup_paths.ps1 -Studio "C:\Program Files\Huawei\DevEco Studio"
```

**新开一个 PowerShell 窗口**（环境变量才会生效）。

## 1.2 跑自检 + 单元测试

```powershell
powershell -ExecutionPolicy Bypass -File scripts\sim_preflight.ps1
```

期望四项：`python` / `port` / `device`（模拟器）/ `hap`。前两项必须 ok；后两项此时可能 fail，正常。

```powershell
python -m unittest discover -s tests -q
```

期望最后一行：`Ran 61 tests in x.xxxs` + `OK`。**这一步通过说明网关代码在你机器上是好的。**

## 1.3 起网关（窗口 A，保持不关）

```powershell
powershell -ExecutionPolicy Bypass -File scripts\demo.ps1 -Siren -Voice
```

期望打印：

```
监听 0.0.0.0:8780
网关地址: http://<你的IP>:8780
持续心跳模式（每 2.0s 一帧）
```

浏览器开 `http://127.0.0.1:8780/` → 应看到看板，左上“网关在线”，中间出现指标。另开窗口（窗口 B）注入一条：

```powershell
cd <你解压的位置>\守夜灯_软件包
python sim\incident.py --type temp
```

看板应出现一条 `L1 温度偏高` 待确认告警，电脑扬声器有提示音（`-Siren -Voice` 已开）。

> 到这一步，**网关 + 判定 + 存储 + 播报** 全部验证完毕，与 APP 无关。

## 1.4 启动模拟器

DevEco Studio → 菜单 **Tools → Device Manager** → **Local Emulator** → 选 `Mate 90 Pro` → **Start**（首次同意协议，冷启 30–60 秒）。

```powershell
& "$env:SHADOWLAMP_STUDIO\sdk\default\openharmony\toolchains\hdc.exe" list targets
# 期望一行：127.0.0.1:5555
```

> 启动失败报 `00801005 内存不足 4.00GB`：关掉浏览器/微信等占内存程序重试；跑 `scripts\emulator_ram.ps1` 可看是谁占着内存。

## 1.5 安装预置 HAP（不用编译）

```powershell
& "$env:SHADOWLAMP_STUDIO\sdk\default\openharmony\toolchains\hdc.exe" install -r dist\entry-default-unsigned.hap
# 期望：install bundle successfully
& "$env:SHADOWLAMP_STUDIO\sdk\default\openharmony\toolchains\hdc.exe" shell aa start -a EntryAbility -b com.shadowlamp.care
```

模拟器桌面上会出现「守夜灯」图标，点开即可。

## 1.6 APP 首启（顺序别反）

1. 首屏是**家庭组欢迎页** → 点 `创建家庭组`
2. 组名 `张家·3楼`，称呼 `大女儿`
3. 网关地址填 **`http://127.0.0.1:8780`**（模拟器和网关在同一台电脑，别填局域网 IP）
4. `确认创建` → 进首页 → 弹新手引导 → `我知道了，开始使用`

**通过标准**：首页五项指标有数并在 2 秒级刷新、右上角绿点“在线”、底部黄字“当前为测试/模拟数据”。

## 1.7 软件侧回归（20 项，15 分钟）

照 `docs/模拟器验收步骤_v2.md` 第 5–13 节走一遍，重点是：

| 场景 | 命令（窗口 B） | 期望 |
|---|---|---|
| 温度 | `python sim\incident.py --type temp` | 首页温度变红 + L1 |
| 湿度 | `python sim\incident.py --type hum` | L2 湿度偏高 |
| 夜间光照 | `python sim\incident.py --type lux` | L1 夜间光照异常 |
| 求助键 | `python sim\incident.py --type sos` | L3，电脑端连续警笛 |
| 白天无活动 | `python sim\incident.py --type idle` | L2 疑似晕倒 |
| 夜间卫生间 | `python sim\incident.py --type night` | L3（最危险组合） |
| 门磁未关 | `python sim\incident.py --type door` | L1，首页门磁 **已开** |
| 复位 | `python sim\incident.py --type reset` | 一切归零 |

告警页还要验证：确认 → 填处置结果 → 提交关闭、导出报告长图、家庭组邀请、关怀模式、一键呼叫（模拟器会打开拨号盘带出号码）。

> ⚠️ 网关刚启动 **180 秒内**不判“无活动/门未关”这类**累积型**告警（防止重启时拿历史时间戳误报）。先演示瞬时场景（SOS/温度/湿度），无活动放到后面。

# 第 2 部分 · 硬件做好之后，用模拟器把软件再跑一遍

前提：板子能连 WiFi、能往网关 `POST /api/v1/snapshot`。此时 APP 侧数据来源会从 `测试/模拟` 变成 **`真实采集`**。

## 2.1 联调前：把网关跑起来（窗口 A）

```powershell
cd <解压位置>\守夜灯_软件包
python run_gateway.py --port 8780 --lan --udp-port 9998 --siren --voice
```

**不要**再用 `demo.ps1` 起模拟设备（它会打 `test` 帧干扰判断）；只看真板子数据。

## 2.2 六条硬判据（逐条打勾）

| # | 判据 | 操作 | 通过标准 |
|---|---|---|---|
| 1 | 真实数据入网 | 板子上电 | 看板出现 `bearpi-001 · 在线`；APP 首页“数据来源”= **真实采集** |
| 2 | 指标真实 | 手捂温湿度传感器 | APP 温度/湿度随之变化，不是“—” |
| 3 | 求助键 | 按板载按键 | APP 立刻 L3 告警 → 电脑警笛 → 板端 LED 快闪 |
| 4 | 本地兜底 | 关掉网关，手遮 PIR 3 分钟 | 板端自己闪灯（不依赖网关） |
| 5 | 下行确认 | APP 里确认该告警 | 10 秒内板端停止响/转绿灯 |
| 6 | 断网续传 | 拔网线/关网关 1 分钟再恢复 | 数据不丢、`seq` 连续、看板无跳变 |

## 2.3 APP 侧回归（真数据版）

数据变成 `hardware` 之后，重跑第 1.7 节的 8 个场景中**能靠真实传感器触发**的那几个：

- 温度/湿度越界（真的捂热/吹气，或改 `config.h` 阈值配合）
- 求助键（真按）
- 门磁（若接了干簧管）
- 无活动（遮住 PIR，白天 5 分钟 / 夜间卫生间 2 分钟）

**不能靠真板子触发的**（没有对应传感器，用注入演示，并在材料里标注“测试数据”）：
`--type lux`（无 BH1750 时）、`--type fire`（无烟感）、`--type gas`（无燃气传感器）。

> 演示时两者要区分清楚：真板子产生的告警来源显示“真实采集”，注入的产生“测试/模拟”。**不要把注入说成真实采集。**

## 2.4 多设备（两台板子 / 板子 + 模拟器）

```powershell
# 给第二块板子改成 CFG_DEVICE_ID = "bearpi-002" 再烧录
python scripts\verify_devices.py        # 校验多设备列表与归属
```

APP「我的」→ 设备切换：两块板子都能看到各自在线状态、待确认条数；切到哪台，首页/告警就只看哪台。

## 2.6 出问题时按这个顺序排

| 现象 | 先查 | 再查 |
|---|---|---|
| 看板没设备 | 网关日志有无 `POST /api/v1/snapshot` | 板子 `CFG_GATEWAY_IP:PORT` 是否是电脑当前 IP |
| 有设备但来源是“测试/模拟” | 帧里 `source` 字段 | 固件 `frame_source()` 是否返回 `hardware` |
| 有数据但没告警 | 是否在 180 秒预热期 | 阈值（`config.h` 与网关 `config.py` 是否一致） |
| 告警不升级 | 网关 `created_at` 是否满足升级间隔 | 该设备是否还有别的待确认告警占着冷却 |
| 板端不响 | `CFG_BUZZER_EN`、GPIO、电平 | `local_rule` 是否被调用（串口日志） |
| APP 收不到新告警 | APP 里网关地址 | APP 是否切到了别的设备 |

# 第 3 部分 · 要改 APP 代码时

## 3.1 一次性准备

1. 用 DevEco Studio **Open** 打开工程目录：`$env:SHADOWLAMP_PROJECT`（默认 `%USERPROFILE%\DevEcoProjects\shadow-lamp-app`）。
   - 如果是新机器，这个目录里没有工程：先在 Studio 里新建空工程同名，或直接从包里复制 `app/ShadowLamp` 过去，再跑一次 `scripts\sync_app.ps1`。
2. 确认 `scripts\setup_paths.ps1` 已跑过（`build_app.ps1` 依赖 `SHADOWLAMP_STUDIO`）。

## 3.2 改完怎么构建 + 装

```powershell
cd <解压位置>\守夜灯_软件包
powershell -ExecutionPolicy Bypass -File scripts\build_app.ps1
# 期望：构建成功 ... entry-default-unsigned.hap

& "$env:SHADOWLAMP_STUDIO\sdk\default\openharmony\toolchains\hdc.exe" install -r `
  "$env:SHADOWLAMP_PROJECT\entry\build\default\outputs\default\entry-default-unsigned.hap"
```

**重要**：源码在 `software\app\ShadowLamp`，构建用的是 `SHADOWLAMP_PROJECT` 里的副本。`build_app.ps1` 现在会**自动先同步**；如果手工在 Studio 里构建，请先跑一次 `scripts\sync_app.ps1`，否则装出来的是旧包（这是历史上最容易“改了没生效”的坑）。

## 3.4 常见编译错误

| 报错 | 原因 | 处理 |
|---|---|---|
| `arkts-no-untyped-obj-literals` | 对象字面量没类型 | 定义 `interface` 后用 `as` 或显式类型 |
| `Cannot find name 'promptAction'` | 用了废弃的全局 API | 改 `this.getUIContext().getPromptAction().showToast()` |
| `00303312 Cannot find the corresponding SDK version` | `DEVECO_SDK_HOME` 指错 | 必须指向 `<Studio>\sdk`（`setup_paths.ps1` 会处理好） |
| 构建成功但界面没变化 | 没同步到工程目录 | 跑 `scripts\sync_app.ps1` 再构建 |
| 装完启动即闪退 | 改了 `module.json5` 权限/页面路径 | `hdc shell hilog -x` 搜 `JSAPP` 看具体错误 |

# 附 · 时间预算

| 阶段 | 时间 |
|---|---|
| 装 Python + DevEco | 30–60 分钟（看网速） |
| 第 1 部分跑通 | 20–30 分钟 |
| 软件侧 20 项回归 | 15 分钟 |
| 硬件上板联调（6 判据） | 1–2 小时（取决于接线与 WiFi） |

有任何卡点，把 **窗口的完整报错 + 网关日志（`data\gw_*.log`）** 一起发出来，比只说“不行”定位快十倍。
