# 模拟器全流程验收步骤（2026-10-28）

## 2026-10-28 修订要点（先看这 5 条）

1. **命令归属**：服务命令在 A 窗（服务窗）、注入命令在 B 窗（注入窗），都要先 `cd D:\shadowlamp`；脚本一律用 `powershell -ExecutionPolicy Bypass -File scripts\xxx.ps1` 调，别直接敲 `demo.ps1 -Stop`。
2. **预热期**：网关启动后 180 秒内不判“无活动/外出/门未关”这类时间累积告警（防重启误报）。要演示这四类场景，先把网关起好等 3 分钟，或把这类场景排到流程后半段。SOS/温湿度/光照不受影响。
3. **白天无活动**用 `--type idle`（L2，白天客厅 10 分钟没动）；**夜间卫生间无活动**用 `--type night`（L3）。
4. **门磁**：`--type door` 注入后首页会持续显示“已开”12 分钟（不会被常规帧覆盖），`--type reset` 立刻恢复。
5. **一键呼叫家属**：模拟器没有拨号应用（`16000019`），会自动降级为“复制号码 + Toast”，真机才拉起拨号盘。

> 环境：DevEco Studio 26.0.0.851（`D:\HarmonySetup\DevEco Studio`）、HarmonyOS 模拟器 `Mate 90 Pro`、
> Python 3.8.10（`D:\HarmonySetup\Python38`）、网关与模拟器同机跑 → APP 里网关地址填 **`http://127.0.0.1:8780`**。

### 0.2 报 `ErrorCode: 00801005 可申请内存不足 4.00GB` 怎么办

这个错是**要不到 4GB 连续内存**，不是模拟器坏了。按顺序处理：

1. **先看内存余量**：
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts\emulator_ram.ps1
   ```
   输出里的 `free`（物理空闲）与 `commit free`（提交余量）任一不足 4GB 都会失败。
2. **关掉占内存的应用**（本机实测：Doubao≈2.3GB、Steam+EOS≈0.8GB、抖音≈0.2GB、Edge≈0.6GB）：
   ```powershell
   Get-Process Doubao,steam,steamwebhelper,EOSOverlayRenderer-Win64-Shipping,douyin -ErrorAction SilentlyContinue |
       Stop-Process -Force
   ```
   ⚠ 不要关浏览器——如果你的 DSH/网页界面在浏览器里，关了就断了；`Weixin` 按需保留。
3. **模拟器内存保持 4096**（**不要降到 3072**）：本机实测降配后会因为 `ram.bin` 里存的是 4GB 的
   VM 快照而报
   `Size mismatch: pc.ram: 0x100000000 != 0xc0000000` / `error while loading state for instance 0x0 of device 'ram'`。
   已经改过的用下面命令还原：
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\emulator_ram.ps1 -Ram 4096 -Apply
   ```
4. 仍失败：**重启电脑**（清理提交/碎片）→ 先起模拟器，再开 DevEco Studio（Studio 自己占 1.2GB 左右）。
5. 装完 APP 后如果想省内存，可以关掉 DevEco Studio，模拟器与 `hdc` 不受影响。

启动后验证（PowerShell）：

```powershell
& "D:\HarmonySetup\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe" list targets
# 期望：127.0.0.1:5555
```

## 5. 逐模块点检（照着点，每步看“期望”）

### 5.1 首页
- 看五项指标：人体活动/温度/湿度/光照/门磁（模拟器每 2 秒变一次）
- 看来源小字：`测试/模拟`；底部有 `⚠ 当前为测试/模拟数据…`
- 期望：顶部绿点、`最后活动 xx 秒前`、电量百分比

### 5.2 一键求助（**长按**，不是点）
- 鼠标在橙色按钮上**按住 1.2 秒**再松
- 期望：`发送中…` → toast `已发出求助，家属会收到告警` → 电脑端警笛 + 语音
- 同时：告警页出现 `紧急 · 紧急求助`，带 `新` 角标

### 5.3 告警页
- 切 `待确认 / 处理中 / 已关闭`
- 点 `全部设备` ↔ `仅 bearpi-001`
- 点开一条未关闭告警 → 详情：等级、时间、区域、编号、处置时间线、建议措施；**听到 TTS 播报**

### 5.4 处置闭环
- 不填直接点 `提交处置并关闭` → 期望 `请填写处置结果`
- 填 `已上门查看，老人安好` → 点 chip `已上门查看` → `确认告警` → 再 `提交处置并关闭`
- 期望：该条进「已关闭」，详情时间线出现处置结果

### 5.5 报告页
- 今日活动（数字 + 较昨日）、时段分布、环境趋势、7 日基线（数据不足时明示）
- 月报：点 `上月` → `本月`
- `导出图` → 全屏预览（黑遮罩 + 白卡 + 双指缩放）→ `保存到相册`（弹权限点**允许**，toast `已保存到相册`）→ `分享给家人`（系统面板 `分享 1 项`）

### 5.6 家庭组
- 我的 → 家庭组卡片 → 详情：组名、成员、6 位密码
- 右上 `邀请家人` → 浮层（大号密码 + 复制 + 二维码）→ 点 `复制` → toast `已复制 6 位密码`
- `退出家庭组` → 再点一次确认 → 回欢迎页（可再建组/加入，验证另一条路径）

### 5.7 设备切换
- 我的 → 设备卡片：`当前：bearpi-001`，每行有来源标签/在线/电量/最后上报
- 输入 `bench-09` → `添加设备` → 期望出现 `bench-09 · 未上报 · 离线 · 电量—`
- 点 `切换` → 绿字 `已切换到 bench-09`（3 秒消失）→ 首页变 `设备离线 · 数据已过期`（因为 bench-09 没数据）
- 切回 `bearpi-001` → 首页恢复

### 5.8 设置项
- `关怀模式（大字）` → 全 APP 字号变大（约 1.32 倍）
- `老人极简首页` → 首页只剩“是否正常 + 一键求助 + 看告警/我的”
- `告警提醒（震动+提示音）` → 注入一条告警，模拟器会响提示音（震动模拟器较弱）
- 个性化设置：温度上限 `33` → `保存阈值` → 注入 `--type temp`（36℃）→ 立刻 L1

### 5.9 离线演练（模拟断网）
1. 停网关：`scripts\demo.ps1 -Stop`
2. APP 里对一条待确认点 `确认告警`
3. 期望：toast `网关不可达：已加入待补发队列，联网后自动提交`；我的页出现 `待补发操作 1 条…`
4. 重开 `scripts\demo.ps1 -Siren -Voice` → 等 10~20 秒（补发 9 秒一轮）→ 计数归零、告警变「处理中」；首页 5~10 秒内回在线

## 6. 场景注入（另开一个窗口，在 `D:\shadowlamp` 下）

| 命令 | 期望现象 |
|---|---|
| `python sim\incident.py --type temp` | 温度变红 + L1 环境提醒（35℃ 默认阈值） |

## 9. 常见错误对照表

| 现象 | 原因 | 处理 |
|---|---|---|
| `hdc list targets` 输出 `[Empty]` | 模拟器没启动/没起来 | `Emulator.exe -start "Mate 90 Pro"`，等 30–60 秒 |
| `ErrorCode 00801005 可申请内存不足` | 空闲/提交内存不到 4GB | 见 §0.2：关占用大的应用 + 保持 4096 + 必要时重启 |
| `Size mismatch: pc.ram` | 改过 `hw.ramSize` 与旧 VM 快照冲突 | `scripts\emulator_ram.ps1 -Ram 4096 -Apply` 还原 |
| `install` 报 `9568289`/签名错误 | 装到了真机 | 模拟器不需要签名；真机要先自动签名 |
| APP 一直“连接失败” | 地址写成电脑局域网 IP 但模拟器同机 | 改 `http://127.0.0.1:8780` |
| 首页指标全是 `—` | 模拟设备没跑 / 数据过期 | 看 demo 窗口是否每 2 秒刷新；`/health` 是否 ok |
| 告警页空 | 停在「仅某设备」而告警属于别的设备 | 切「全部设备」 |
| 点求助没反应 | 用了单击 | **长按 1.2 秒** |
| 保存相册失败 | 没给相册权限 | 弹窗点允许；拒绝会走系统代存 |
| 一键呼叫家属报“不支持拨号” | 模拟器没有电话应用 | 预期现象，真机才拉起拨号盘 |
| TTS 没声音 | 模拟器缺中文语音包 | `hilog` 看 `[TtsManager] init failed`；真机一般自带 |
| 导出图没反应 | 截图 API 异常 | `hilog` 搜 `ReportTab|createFromBuilder` |
| 网关端口被占 | 上一轮没停干净 | `scripts\demo.ps1 -Stop`，或 `-Port 8790` |
