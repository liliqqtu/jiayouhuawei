# 家庭组管理员与通知栏提醒（2026-11-03）

本文记录本轮两项改动的实现口径、验证结果与演示要点，供队友接手与答辩引用。

## 1. 户主即管理员，管理员可增删成员

### 1.1 网关侧（`software/gateway/`）

- `family.py` 增加第三种身份 `admin`：
  - `ROLE_OWNER = "owner"`（户主）、`ROLE_ADMIN = "admin"`、`ROLE_GUARDIAN = "guardian"`；
  - `ADMIN_ROLES = (owner, admin)`：户主天然拥有管理员权限，不用额外赋权；
  - 成员视图新增 `isAdmin`，家庭组视图新增 `ownerId`、`adminCount`，APP 直接拿来判断要不要显示管理入口。
- 新增两个能力（`FamilyRegistry.add_member` / `remove_member`）：
  - 只有管理员能调用；非成员 403 `NOT_MEMBER`，普通监护人 403 `NOT_ADMIN`；
  - 添加成员：称呼最长 12 字、重名 409 `MEMBER_EXISTS`、身份只能是 guardian/admin（400 `BAD_ROLE`）；
  - 删除成员：户主不可删（400 `CANNOT_REMOVE_OWNER`），成员不存在 404 `MEMBER_NOT_FOUND`。
- 路由（`gateway/api.py`）：

| 方法 | 路径 | 请求体 | 说明 |
| --- | --- | --- | --- |
| POST | `/api/v1/family/member/add` | `{familyId, operator, name, role}` | 管理员添加成员，`role` 取 `guardian`/`admin` |
| POST | `/api/v1/family/member/remove` | `{familyId, operator, memberId}` | 管理员移除成员 |

`operator` 是操作者的称呼（APP 用它自称身份），也可换成 `operatorId`。家庭组仍是网关内存态，重启后组与密码一起重置——与合入前的行为一致，没有额外引入持久化。

### 1.2 APP 侧（`software/app/ShadowLamp/entry/src/main/ets/`）

- `model/Models.ets`：`FamilyMember` 增加 `isAdmin`；`FamilyInfo` 增加可选 `ownerId`、`adminCount`。
- `service/FamilyStore.ets`：新增 `memberId` 持久化、`isAdmin()`、`applyRole()`；`roleText()` 支持"管理员"。
- `service/ApiClient.ets`：新增 `familyAddMember()`、`familyRemoveMember()`，沿用 `sendFamily` 的错误码透传。
- `pages/FamilyPage.ets`：
  - 新增"成员管理"卡片（仅管理员可见）：填称呼 + "设为管理员"开关 + 确认添加；
  - 成员行右侧出现"移除"，第一次点变为"确认移除"（防误触），户主那一行不显示移除；
  - 每次刷新都用网关成员表对齐自己的身份，被提成管理员/被降级后界面立即跟着变。
- `view/MineTab.ets`：家庭组卡片身份文案支持"管理员"。

设计取舍：
- 让户主直接加人，而不是让对方扫码——老人与社工都不会走"扫码 → 注册 → 输密码"那条路；家庭组本来就是熟人小圈子，管理员的信任边界由户主自己把握。
- 户主不可被移除：否则这个组会留下"没人能管成员"的死角；真要换户主就重建家庭组。

## 2. 预警进手机通知栏

### 2.1 实现

- 新增 `service/Notifier.ets`：
  - 首次进首页调用 `notificationManager.isNotificationEnabled()`，未授权则 `requestEnableNotification()` 弹系统授权框；
  - `addSlot(SlotType.SOCIAL_COMMUNICATION)` 建通道——该类型对应 `LEVEL_HIGH`，会在屏幕顶部弹横幅，符合"手机通知栏上方显示通知"的要求；
  - `publish()` 发 `NOTIFICATION_CONTENT_BASIC_TEXT` 通知，标题"守夜灯 · 紧急告警/重要告警/提醒"，正文用最高等级那条告警的原文；点通知回到 APP（WantAgent `START_ABILITY`）；
  - 同一事件 20 秒内只弹一次，避免 3 秒轮询把一条告警刷成六条；
  - 失败一律 `console.warn` 后静默降级，不影响原有的震动 + 提示音。
- `pages/Index.ets`：3 秒轮询里原逻辑不变（等级序 + 条数变差才提醒），新增 `Notifier.init()` 与 `Notifier.alarm()`；待确认告警条数归零时 `cancelAll()`，免得处理完的告警还挂在通知栏。

### 2.2 能力边界（答辩要主动说）

- 这是**本地通知**，不需要推送服务、不需要服务端与证书；代价是 APP 进程被系统冻结后不会再产生通知。
- 用户拒绝通知授权时静默降级：震动与提示音仍然有效，不会出现"点了拒绝就完全收不到"的情况。
- 已处置完的告警会被清空通知，避免"事情早解决了，通知还挂着"。

## 4. 演示脚本（约 30 秒）

1. 户主创建家庭组 → 家庭组页出现"成员管理"卡片 → 添加"社区网格员"并打开"设为管理员" → 成员数 +1，身份 chip 显示"管理员"；
2. 长辈账号（监护人）进入同一页面 → 只能看到成员列表，"成员管理"卡片与"移除"按钮都不出现；
3. 点某个成员"移除" → 按钮变为"确认移除" → 再点一次 → 成员消失；
4. 造一条 SOS 或烟感告警（`python sim/incident.py` 或 `scripts/incident.ps1`）→ 手机顶部弹出"守夜灯 · 紧急告警"横幅；告警在 APP 里处置完 → 通知自动消失。
