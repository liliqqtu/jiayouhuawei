# 守夜灯 · 全链路真机实操验收手册（2026-10-28）

> 适用：校赛前真机验收（HarmonyOS 手机 + Windows 网关）。
> 代码基线：`entry/src/main/ets/` 21 个 .ets，6001 行；网关 61 项 unittest 全过。
> 每条测试都给了「预期 UI / Toast / 日志」与「异常排雷（看哪段代码、怎么抓日志）」。

## 0. 真机开测前的 6 件必做（90% 的“连不上”都出在这里）

| # | 事项 | 做法 | 失败现象 |
|---|---|---|---|
| 0.1 | **签名** | 华为手机装不了未签名包。DevEco Studio → File → Project Structure → Signing Configs → 勾 `Automatically generate signature`（需登录华为账号）→ 重新 Build。产物在 `entry/build/default/outputs/default/entry-default-signed.hap` | `hdc install` 报 `9568289 … sign` / 装不上 |
| 0.2 | **同网** | 手机与电脑连同一个 Wi-Fi。手机**关掉移动数据**（否则请求走蜂窝网，永远连不上内网） | 一直转圈、提示无法连接 |
| 0.3 | **防火墙** | Windows 防火墙放行 8780 入站：`netsh advfirewall firewall add rule name="shadowlamp-8780" dir=in action=allow protocol=TCP localport=8780` | 电脑本机 curl 通、手机不通 |
| 0.4 | **网关带 --lan** | `python run_gateway.py --port 8780 --lan --udp-port 9998 --siren --voice`；启动日志会打印 `监听 0.0.0.0:8780` 与局域网地址 | 只有 `127.0.0.1` 监听 → 手机连不上 |
| 0.5 | **地址核对** | 电脑 `ipconfig` 取 IPv4（如 `10.202.43.46`），APP「我的」填 `http://10.202.43.46:8780` | 填了 `192.168.1.100` 默认值 → 连不上 |
| 0.6 | **抓日志** | `hdc list targets` → 有设备后：`hdc shell hilog -x | Select-String "JSAPP|TtsManager|CallUtils"` | 出问题看不到日志 = 无法排雷 |

> 手机浏览器先打开 `http://<电脑IP>:8780/health`，能看到 `{"ok":true,...}` 再进 APP。

## 一、功能盘点（源码实测，按页面归并）

### 1.1 页面与路由（`resources/base/profile/main_pages.json`）

| 页面 | 文件 | 进入方式 | 主要职责 |
|---|---|---|---|
| 首页 | `pages/Index.ets`（170 行） | 启动 | 4 个 Tab 容器（首页/告警/报告/我的）+ 首启引导浮层 + 家庭组判定 |
| 家庭组欢迎 | `pages/FamilyWelcome.ets`（326 行） | 未加入家庭组时 `replaceUrl` | 创建 / 用密码加入 两态表单 |
| 家庭组详情 | `pages/FamilyPage.ets`（427 行） | 我的 → 家庭组卡片 `pushUrl` | 组名、成员、6 位密码、复制、二维码、退出 |

### 1.2 首页 `view/HomeTab.ets`（598 行）

- 五项指标：人体活动（PIR）、温度、湿度、光照、门磁（`MetricCell` 组件，`view/MetricCell.ets`）
- 状态卡三态：`一切正常` / `发现异常待确认` / `设备离线 · 数据已过期`
- 数据来源标签：`真实设备(hardware)` / `测试/模拟(test)`；未接传感器显示 `—`（不编造）
- 最后活动时间、电量、在线状态、网关地址、更新时间
- 一键求助按钮：`LongPressGesture(duration: 1000)` 长按 1 秒 → `triggerSos()`
- 老人极简模式（`elderHome` 开关）：超大「是否正常」+ 一键求助 + 看告警/我的
- 3 秒 tick（`@Watch('onTick')`）刷新 + 每 3 秒拉快照 `GET /api/v1/snapshot`

### 1.3 告警 `view/AlarmTab.ets`（749 行）

- 三筛选：`待确认(pending)` / `处理中(acknowledged)` / `已关闭(closed)`
- 设备范围切换：`全部设备` ↔ `仅 <当前设备>`
- 卡片：等级色条（L3 红/L2 橙/L1 蓝）、等级·消息、时间、设备 ID、`新`角标、状态、来源标签
- 详情页：等级+类型、标题、触发时间/区域/来源/告警编号、触发时数据、处置时间线（触发→确认→关闭）、建议措施、`一键呼叫家属`、处置结果输入（≤200 字）、处置 chips（已上门查看/电话确认/误报/转社区/其他）、`确认告警`、`提交处置并关闭`
- 打开详情时 TTS 播报（仅未关闭告警）
- 离线只读：`离线状态只能查看，处置需要连接网关`
- 离线时确认/提交 → 入 `Outbox` 待补发队列
- 详情内部 3 秒刷新（`refreshDetail`）

### 1.4 报告 `view/ReportTab.ets`（923 行）

- 今日活动次数 + 较昨日对比
- 时段分布（每 2 小时柱状，24 格）
- 环境趋势（最近 24 帧温度柱状）
- 7 日基线（连续 3 日低于基线 30% 才提示；数据不足显示“数据不足”）
- 月报：`本月` / `上月` 两个 chip，取 `GET /api/v1/reports/monthly?month=YYYY-MM`
- `导出图` → 长图（720vp 宽、2 倍像素）→ 全屏预览（遮罩+白卡+双指缩放）→ `保存到相册` / `分享给家人`

### 1.5 我的 `view/MineTab.ets`（794 行）

- 家庭组入口卡片（组名 · 身份）
- 网关地址 + `保存并测试连接`（GET `/health`）
- 设备切换：列表（名称/来源标签/在线/电量/最后上报/当前/切换）、设备编号输入 + `添加设备`（POST `/api/v1/devices`）、10 秒轮询 `GET /api/v1/devices/status`、网关离线红字提示
- 关怀模式（大字）开关 → `Theme.largeScale = 1.32`
- 告警提醒（震动+提示音）开关 → `service/Alerter.ets`
- 老人极简首页开关
- 待补发操作数量提示（`Outbox`）
- 个性化设置：温度上限、湿度上限、无活动分钟、家属电话、午睡智能抑制 → `保存阈值`（POST `/api/v1/config/threshold`）

## 二、验收清单（真机逐条点，边点边打勾）

> 通用抓日志：`hdc shell hilog -x | Select-String "JSAPP"`（PowerShell）。
> 网关日志：`software/data/gateway.log` / `demo_gateway.log`，每次请求打印方法+路径+状态。

### T01 首启顺序（**先家庭组、后新手引导**，顺序别搞错）
- **目的**：验证 `Index.bootstrap` 的判定顺序与引导只出现一次。
- **真实顺序**（源码 `pages/Index.ets:55-67`）：装好打开 → 没加入家庭组 → 直接 `replaceUrl` 到 **家庭组欢迎页** → 建组/加入后回首页 → 这时才弹**新手引导浮层**（三步用起来 / 声音分级 / 遇到情况先做什么 / 数据诚实说明）→ 点 `我知道了，开始使用` → 首页。
- **预期**：杀进程重开，家庭组与引导都不再出现（Preferences `joined` / `guideDone`）。
- **排雷**：一直弹引导 → `Settings.markGuideDone()` 没写成功；一直进欢迎页 → `FamilyStore.joined` 没置 true（`FamilyStore.ets` put 后忘了 `flush`）。

### T02 网关地址配置
- **目的**：验证 /health 联通与地址持久化。
- **步骤**：「我的」→ 网关地址输入 `http://<电脑IP>:8780` → 点 `保存并测试连接`。
- **预期**：按钮变 `连接中…` → 绿字 `连接成功，可以开始演示`；失败是红字 `连接失败：检查网关是否用 --lan 启动、手机与电脑是否同一 WiFi`；成功后重启 APP 地址还在。
- **排雷**：红字 = 网络层。依次查 0.2/0.3/0.4/0.5；网关日志有没有收到 `GET /health`（收到=APP 通了，回包问题；没收到=根本没到电脑）。

### T03 首页看板
- **目的**：验证五项指标、来源标签、3 秒刷新。
- **步骤**：回「首页」；另开窗口跑 `python sim\device_sim.py --loop`。
- **预期**：指标从 `—` 变成数字并持续变化；来源显示 `测试/模拟` 或 `真实设备`；底部声明 `⚠ 当前为测试/模拟数据…`；顶部状态点绿。
- **排雷**：一直 `—` → `@Watch('onTick')` 没触发 / 快照解析；看 `[device]` 与 `RCP` 日志。

### T04 一键求助（长按 1 秒）
- **目的**：验证 SOS 全链路（APP→网关→告警→声光语音）。
- **步骤**：首页长按橙色 `一键求助` 1 秒（**不要只点**）。
- **预期**：按钮 `发送中…` → 首页 toast `已发出求助，家属会收到告警` → 网关警笛 + 语音「警告，监测到紧急求助，请立即处理」→「告警」页出现 `紧急 · 紧急求助` 新卡（带 `新` 角标）。
- **排雷**：点了没反应 → 用的是 `LongPressGesture`，短按不触发；发送失败 toast `发送失败：网关未连接` → 网络问题。

### T05 告警列表与筛选
- **目的**：验证三种状态筛选与设备范围切换。
- **步骤**：告警页 → 依次点 `待确认`/`处理中`/`已关闭` → 点 `全部设备` 与 `仅 <当前设备>` 互切。
- **预期**：列表随筛选变化；空态显示 `暂无告警`；离线时顶部红字 `网关离线：下面的是上次取到的列表，状态可能已过期`。
- **排雷**：明明有告警却不显示 → 大概率在「仅当前设备」而告警属于另一台设备；切「全部设备」。

### T06 告警详情与证据
- **目的**：验证详情渲染、时间线、TTS 播报。
- **步骤**：点任意未关闭告警卡片。
- **预期**：进入详情；左上 `‹ 返回`；有等级 chip、触发时间/区域/来源/编号；`处置时间线` 显示 触发→等待确认→尚未关闭；到详情时听到中文播报（真机外放）。
- **排雷**：详情空白 → 解析异常，hilog 搜 `AlarmTab`；时间线只有一行 → 该条是旧数据没有 evidence 字段（正常）。

### T07 确认告警
- **目的**：验证 pending→acknowledged 状态迁移。
- **步骤**：详情页点蓝色 `确认告警`。
- **预期**：返回列表，该条出现在「处理中」；详情状态显示 `处理中`。
- **排雷**：提示 `网关不可达：已加入待补发队列…` → 网络断，检查网关；提示 `该告警状态已变化，列表已刷新` → 409（另一台手机已确认）。

### T08 提交处置并关闭
- **目的**：验证必填校验 + 闭环。
- **步骤**：打开处理中告警 → 不填直接点 `提交处置并关闭` → 再填 `已上门查看，老人安好` + 点 chip `已上门查看` → 再提交。
- **预期**：第一次提示 `请填写处置结果`；第二次回列表、该条进「已关闭」，详情时间线出现处置人与结果。
- **排雷**：一直转 `提交中…` → 网关无响应（看网关日志有没有 500）；处置结果 >200 字会被截断。

### T09 离线队列（断网可操作）
- **目的**：验证断网暂存 + 联网补发。
- **步骤**：打开一条待确认 → **关掉电脑网关**（或手机断 Wi-Fi）→ 点 `确认告警` → 看「我的」页 → 重开网关 → 等 10~20 秒（补发是 **9 秒一轮**，`Index.ets` 的 `flushTimer`）。
- **预期**：toast `网关不可达：已加入待补发队列，联网后自动提交`；「我的」出现 `待补发操作 1 条…`；联网后自动提交、计数归零、该条变「处理中」。
- **排雷**：不补发 → `Outbox.flush` 触发点（`aboutToAppear`/定时）；RDB `pending_op` 表用 `hdc shell` 看不到，看 hilog `Outbox`。

### T10 报告页基础
- **目的**：验证统计与图表。
- **步骤**：「报告」页看：今日活动、时段分布、环境趋势、7 日基线。
- **预期**：数字与网关数据一致；无历史时基线显示 `数据不足`；柱状图无溢出。
- **排雷**：全 0 / 全 `—` → 周报接口 `GET /api/v1/reports/weekly` 失败，看网关日志。

### T11 月报（本月/上月）
- **目的**：验证赛题四「周/月报告」。
- **步骤**：报告页下滑到月报区 → 点 `上月` → 点 `本月`。
- **预期**：切换月份重新取数；断网时显示 `—` 且下方说明 `未取到月报数据…`（**不显示 0**，这是数据诚信设计）。
- **排雷**：一直 `—` → `ApiClient.monthly(monthKey)` 失败；看网关 `GET /api/v1/reports/monthly`。

### T12 导出长图
- **目的**：验证离屏截图与预览。
- **步骤**：报告页点 `导出图`。
- **预期**：按钮 `生成中…` → 全屏预览：黑底遮罩 + 白卡（标题/等级/三块指标/7 日柱状/温湿度/结论/水印含网关与“测试/模拟”）+ 右上 ✕；双指可放大 1–4 倍。
- **排雷**：点了没反应 → 截图 API 抛错，hilog 搜 `ReportTab|createFromBuilder`；预览空白 → `ReportExporter` 打包失败。

### T13 保存到相册
- **目的**：验证权限申请 + 相册写入（含退让路径）。
- **步骤**：预览页点 `保存到相册`。
- **预期**：首次弹系统权限 `允许“守夜灯”修改你的图片和视频?` → 允许 → toast **`已保存到相册`**、预览关闭；系统相册里能看到该长图。
- **排雷**：授权后仍失败 → `report_file` 写入沙箱失败；拒绝权限时走 `showAssetsCreationDialog` 系统代存，同样能进相册（**答辩可演示这条退让**）。

### T14 分享给家人
- **目的**：验证 ShareKit 拉起系统分享。
- **步骤**：预览页点 `分享给家人`。
- **预期**：系统面板 `分享 1 项`（约 350KB）+ 华为分享/复制/保存至图库/打印；关闭后回到报告页。
- **排雷**：提示 `分享面板打开失败` → URI 非法（必须 `fileUri.getUriFromPath`，已修）；模拟器上属常见。

### T15 家庭组：创建
- **目的**：验证首启建组。
- **步骤**：清应用数据/首次进入 → 欢迎页 `创建家庭组` → 填 家庭组名称（如 `张家·3楼`）、我的称呼（如 `大女儿`）、网关地址 → `确认创建`。
- **预期**：直接进首页；「我的」顶部显示 `张家·3楼 · 户主`。
- **排雷**：提示 `请先输入…` → 校验未过；`连不上网关` → T02；家庭组只存在网关内存，**重启网关会重置**。

### T16 家庭组：邀请与复制
- **目的**：验证密码/二维码分发。
- **步骤**：「我的」→ 家庭组 → 右上 `邀请家人`。
- **预期**：底部浮层：大号 6 位密码 + `复制` + 二维码 + 关闭；点复制 → toast `已复制 6 位密码`。
- **排雷**：二维码空白 → `QRCode` 生成参数；复制失败 → 剪贴板权限，会提示 `复制失败，请手动念给对方`。

### T17 家庭组：加入（第二台手机）
- **目的**：验证多成员共享。
- **步骤**：第二台手机（同一 Wi-Fi、同一网关地址）→ 欢迎页 `用密码加入` → 输入 6 位密码 + 称呼 → `加入`。
- **预期**：加入成功进首页；两台手机各自看到成员列表 2 人；数据一致。
- **排雷**：`484 网关重启过` → 网关重启导致组重置；`找不到这个密码` → 密码输错/组已重置。

### T18 家庭组：退出
- **步骤**：家庭组页 → `退出家庭组` → 再点一次确认。
- **预期**：回到欢迎页；「我的」家庭组卡片显示未加入。
- **排雷**：退出后仍显示旧组 → `FamilyStore.clear()` 未写 Preferences。

### T19 设备切换
- **目的**：验证全局刷新链路。
- **步骤**：「我的」→ 设备卡片 → 点某台设备右侧 `切换`。
- **预期**：绿字 `已切换到 xxx`（3 秒消失）；顶部 `当前：xxx`；回首页数据变成该设备的；切到离线设备 → 首页 `设备离线 · 数据已过期`；告警页范围标签跟着变。
- **排雷**：切换后首页不变 → `AppStorage('deviceId')` 没写入 / 首页 `@Watch('onDeviceChange')` 未触发。

### T20 添加设备（不造假数据）
- **目的**：验证占位登记与失败提示。
- **步骤**：输入 `bench-99` → `添加设备`；然后关掉网关再添加 `bench-100`。
- **预期**：成功 → 列表出现 `bench-99 · 未上报 · 离线 · 电量—`；失败 → 红字 `无法连接网关，请先保存并测试连接`，列表不变。
- **排雷**：成功后列表没变 → 10 秒轮询未到，下拉/切页重进；网关日志应看到 `POST /api/v1/devices 200`。

### T21 关怀模式（大字全局）
- **目的**：验证 1.32 倍缩放全局生效且持久化。
- **步骤**：「我的」打开 `关怀模式（大字）` → 依次看首页/告警/报告/我的。
- **预期**：所有页面字号放大、按钮/行高不重叠；重启 APP 仍是大字。
- **排雷**：部分页面没变 → 该处字号没走 `Theme.fs(base, largeFont)`，全局搜 `fontSize(` 硬编码。

### T22 老人极简首页
- **步骤**：「我的」打开 `老人极简首页` → 回首页。
- **预期**：首页只剩 是否正常 + 一键求助 + 看告警/我的 两个大按钮；关闭开关恢复完整看板。
- **排雷**：切换后布局错乱 → `elderHome` 的 `if/else` 分支。

### T23 告警提醒（震动 + 提示音）
- **步骤**：打开开关 → 网关注入一条新告警（`python sim\incident.py --type temp`）→ 停在告警页。
- **预期**：手机震动 + 提示音（前台，15 秒节流，避免刷屏）。
- **排雷**：不响 → 系统静音/媒体音量为 0；`Alerter` 初始化失败会在 hilog 打 warn。

### T24 语音播报（TTS）
- **步骤**：点开未关闭告警详情。
- **预期**：听到「警告，监测到紧急求助，请立即处理」（L3）或「提醒，监测到…」（L1/L2）；已关闭告警点开不播。
- **排雷**：无声 → `hdc shell hilog -x | Select-String "TtsManager"`：`init failed` 说明缺引擎（部分机型需在设置里下载中文语音包）。

### T25 一键呼叫家属
- **步骤**：详情页点红色 `一键呼叫家属`。
- **预期**：拉起系统拨号盘，号码预填 `13800138000`（可在「我的-个性化设置-家属电话」改），用户点绿键才真正拨出。
- **排雷**：提示 `这台设备不支持拨号，请手动拨打…` → 无拨号应用/被管控；hilog 搜 `CallUtils`。

### T26 个性化阈值
- **步骤**：「我的」→ 个性化设置 → 填 温度上限 `33`、无活动分钟 `3` → `保存阈值` → 网关注入 `--type temp`（36℃）。
- **预期**：保存成功提示；注入后按新阈值（33℃）立刻产生 L1 环境提醒。
- **排雷**：保存失败 → `POST /api/v1/config/threshold`；注意阈值改动影响比赛演示口径，演示完改回默认（35/80/5）。

### T27 持久化与重启
- **步骤**：杀掉 APP（后台清掉）→ 重开。
- **预期**：网关地址、设备选择、大字、家庭组、告警缓存都在；告警页先显示本地缓存再拉网（弱网时不会白屏）。
- **排雷**：全丢 → Preferences/RDB 初始化失败，hilog 搜 `AlarmStore|Outbox`。

### T28 弱网/离线全链路
- **步骤**：断网 → 首页（应显示“设备离线·数据已过期”+ 最后上报时间）→ 告警页（离线只读红字）→ 恢复网络。
- **预期**：5–10 秒内自动恢复在线；期间待补发操作自动提交。
- **排雷**：恢复后仍离线 → 3 秒轮询已停（页面切走再回来）；或网关已重启换了 IP。

## 三、校赛路演剧本（6 分钟版，可压到 4 分钟）

> 目标：**先给人看“正在发生的事”，再讲架构**。评委记住的是“报警响了 + 处置闭环 + 一家人共享”。

### 0:00–0:30 一句话立题
「我们做的是独居老人的守夜灯：他不戴设备、不学操作，家里有人活动就没事；一旦长时间没动静或按了求助，家属手机立刻响，并且能当场把这件事处理完。」
**动作**：手机已停在首页（在线、一切正常）。

### 0:30–1:10 首页：一眼看清
- 指指标：人体活动 / 温湿度 / 光照 / 门磁 / 电量。
- 指来源标签：「现在演示用的是模拟数据，这里明确标了『测试/模拟』——我们不拿假数据装真传感器。」
**话术**：「五项指标 + 在线状态 + 数据来源，老人家里什么情况，一眼看完。」

### 1:10–2:00 核心：一键求助 → 告警 → 详情
1. 长按 `一键求助` 1 秒（**现场一定要说“长按 1 秒防误触”**）。
2. 网关警笛 + 语音播报（**把电脑音量开大，这是全场最响的一下**）。
3. 切「告警」页：新卡带 `新` 角标。
4. 点开详情：等级、时间、区域、编号、**处置时间线**、建议措施。
5. 点 `一键呼叫家属` → 真机拉起拨号盘（**不拨出，展示“预填、不代拨”**）。
**话术**：「告警不是一条消息，是一条有状态、有时间线、能一步打出电话的事件。」

### 2:00–2:40 处置闭环
- 填 `已上门查看，老人安好` → 点 chip `已上门查看` → `确认告警` → `提交处置并关闭`。
- 卡片进「已关闭」，详情时间线完整。
**话术**：「确认、处置、关闭全部落库，形成居家安全日志——评委能查到每一次处置是谁、什么时候做的。」

### 2:40–3:20 三级判定 + 融合规则（讲，不点）
- L1 提醒（两声轻）/ L2 关注（三声）/ L3 紧急（连续警笛直到有人处理）。
- 三条融合：外出抑制、夜间加权（卫生间 5 分钟→2 分钟）、冷却去重。
- 现场可选：注入 `python sim\incident.py --type temp` 演示 L1 环境提醒（36℃ 变红）。

### 3:20–4:00 报告：从“报警”到“看趋势”
- 今日活动、时段分布、7 日基线（连续 3 天低于基线 30% 才提示）、月报本月/上月。
**话术**：「异常是点，趋势是线。老人活动量连续下降，比一次报警更早预告问题。」

### 4:00–4:40 导出与分享（视觉收尾）
- `导出图` → 长图预览 → `保存到相册` / `分享给家人`。
**话术**：「家属可以一条微信把这份安全报告发给兄弟姐妹或社区网格员。」
（**权限弹窗留在这里演示**，提前说明“首次会要一次相册权限”。）

### 4:40–5:20 一家人共享 + 多设备
- 「我的」→ 家庭组：户主/监护人、6 位密码、二维码。
- 设备切换：切到另一台设备 → 首页立刻变。
**话术**：「一个老人一个家庭组，谁在家、谁出门、有没有异常，一家人看的是同一份数据。」

### 5:20–6:00 收尾（一句话 + 事实）
「硬件是 BearPi-HM Nano + E53-IS1，南向 GPIO/I2C 采集加本地阈值兜底，北向 ArkTS，网关 Python 纯标准库。今天演示的是模拟数据，传感器接上后会自动变成『真实设备』标签——这条链路我们没改代码。」

**时间不够就砍**：4:00–4:40（导出）与 4:40–5:20（家庭组）只讲不点，保留 1:10–2:40 的报警闭环。

## 四、现场翻车急救预案

### 场景 A：局域网断了 / 网关连不上（最常见）
**症状**：首页转圈、`连接失败`、告警页红字「网关离线」。
**30 秒动作**：① 手机看 Wi-Fi 是否被切到 4G；② 电脑跑 `ipconfig` 看 IP 是否变了（换网/重连会变）；③ 手机浏览器开 `/health` 验证。
**话术**：
> 「现场 Wi-Fi 是共享网络，网关刚才被 DHCP 换了地址。正好借这个演示一下降级设计——APP 会保留最后一份数据并明确标注『设备离线 · 数据已过期』，不会假装一切正常，也不会白屏。」
**兜底**：切到「报告」页（历史数据本地缓存可看）→ 播放提前录好的 5 分钟演示视频。

### 场景 B：真机权限弹窗/闪退
**症状**：点保存相册弹权限、点分享无反应、某页闪退。
**动作**：权限 → 直接点「允许」并继续；闪退 → 重启 APP（数据都在 Preferences/RDB，不会丢）。
**话术**：
> 「相册写入是系统权限，第一次会弹窗，这是 HarmonyOS 的安全设计。如果拒绝，我们还有一条退让路径——系统代存到图库，功能不中断。」
**兜底**：跳过导出，用「报告页 + 长图截图」代替；或直接放视频里这一段。

### 场景 C：UI 被遮挡 / 卡死 / 点击无响应
**动作**：先 `返回` 再进页面；长按卡片无反应就换点「告警」Tab；实在卡住 → 杀进程重开（10 秒内恢复，数据不丢）。
**话术**：
> 「刚才点的是长按手势，我重来一次。它设计上就是要『长按 1 秒防误触』，这是给老人用的，不能一点就报。」
**兜底**：转 PPT 对应页讲设计，避免在手机上反复试。

### 场景 D：告警不出现 / 声音不响
**动作**：看网关日志有没有 `POST /api/v1/snapshot`、`POST /api/v1/sos`；电脑音量、Windows 输出设备。
**话术**：
> 「注入脚本在跑，网关日志是实时打印的——这里能看到事件的完整链路。」
**兜底**：直接打开「告警」页已有的历史告警讲详情与闭环（不依赖现场注入）。

### 万能兜底顺序（背下来）
1. 先讲降级设计（离线可看、数据诚信、不白屏）→ 2. 换到报告/家庭组页（不依赖实时链路）→ 3. 放 5 分钟演示视频 → 4. 回到 PPT 讲架构与测试数据。
