# 独居老人居家安全监测与应急辅助系统 —— 设计方案

## 一、 项目背景与设计目标

### 1.1 项目背景
随着我国人口老龄化进程加速，高龄空巢、独居老人的比例持续攀升。独居老人由于身体机能衰退，极易在日常生活中发生突发性疾病、意外跌倒、夜间迷途走失或室内用电用火安全事故。然而，由于独居缺乏常态化照料，老人在遭遇突发意外时往往无法自主报警或及时呼救，造成“黄金抢救时间延误”，极易酿成严重人身安全后果。

传统基于穿戴式设备（如智能手环、跌倒手表）的监护方案，由于需要老人频繁充电、主动佩戴，极易因老人遗忘、排斥佩戴而造成监护“窗口期”失效；而传统的室内网络摄像头方案又存在严重的隐私侵犯隐患，在卫生间、卧室等高危跌倒场所难以部署。

### 1.2 设计目标
针对上述社会痛点，本项目基于开源鸿蒙（OpenHarmony）轻量系统与北向分布式应用架构，研发了一套**“非感官接触式、高隐私保护、软硬件南北向一体化”**的独居老人居家安全监测与应急辅助系统。系统旨在实现：
1. **多维度被动感知**：利用热释电红外人体感应、干簧管门窗磁传感器、微气候温湿度传感器，实现老人活动轨迹与出入状态的隐形守护，免除穿戴负担；
2. **抢占式主动呼救与本地声光联动**：提供随身便携式紧急 SOS 按键，结合现场蜂鸣器与爆闪 LED，在异常发生瞬间拉响现场警报，震慑风险并呼唤邻里关注；
3. **北向全景监控与智能健康规律分析**：构建老人日常生活规律图谱，自动统计分析 24 小时活跃时段分布及 7 日活动趋势，辅助子女及早研判老人身体衰退征兆；
4. **事件闭环管理工作台**：预警发生后，子女与社区网格员可一键确认、排查、反馈处置结论，形成电子化居家安全日志台账，实现安全隐患全周期闭环追踪。

## 二、 系统总体技术架构

系统整体遵循 OpenHarmony “软硬协同、南北结合、统一互联”的技术架构原则，分为**南向设备感知层**、**通信传输层**以及**北向综合控制与闭环管理层**三层架构体系。

1. **南向设备感知控制层**：运行 OpenHarmony LiteOS-M 内核，主控采用海思 Hi3861V100 RISC-V 架构芯片，多任务实时调度红外人体感应、干簧管门窗磁开关、SOS 求助键与室内微气候检测，通过本地状态机实现毫秒级声光告警与自主消警仲裁。
2. **通信传输层**：采用轻量级、自解释的统一 JSON 数据协议，支持 UART 串口直接遥测流与 Wi-Fi 协议栈双轨并发，保障现场路演、家庭内网与云端跨网的多模稳定通信。
3. **北向综合控制与闭环管理层**：基于现代化响应式架构构建，提供实时感知态势、预警弹窗调度、事件处置录入及老人生活规律大数据可视化呈现。

## 三、 硬件选型与引脚电气设计

### 3.1 核心硬件选型
- **核心主控开发板**：小熊派 BearPi-HM Nano。搭载海思 Hi3861V100 高度集成 2.4GHz Wi-Fi SoC 芯片，集成 32 位 RISC-V 微控制器，最大主频 160MHz（等效性能强劲），内置 352KB SRAM 与 288KB ROM，支持硬件浮点与安全引擎，专为物联网与 OpenHarmony 轻量设备开发设计。
- **人体活动感应扩展板**：BearPi E53_IS1。集成数字热释电红外传感器与高分贝无源蜂鸣器，有效感应角度达 100°，感应距离达 3~5 米，检测到有人走动时输出高电平脉冲。
- **门窗磁传感器**：高灵敏度磁敏干簧管组件。采用磁性接近吸合原理，门窗关闭时磁铁吸合触点导通接地；门窗打开时触点断开，利用芯片内部上拉输出高电平，具有无机械磨损、零待机功耗、高可靠等特性。
- **环境温湿度传感器**：E53_IA1 板载工业级 SHT30 I²C 传感器（集成微气候动态平滑补偿算法），测温精度达 ±0.2℃，测湿精度达 ±2%RH。
- **紧急求助输入**：板载微动轻触按键 F1 与消警按键 F2，自带硬件抗冲击设计。

### 3.2 硬件引脚分配与防冲突设计
针对 E53 接口标准与扩展座硬件布局，经过精细排查与电气核算，彻底解决了 GPIO 复用冲突，最终硬件管脚分配如下：

| 功能模块 | 对应外设 / 器件 | 硬件 GPIO 映射 | J1 扩展座管脚 | 信号方向与配置属性 |
| :--- | :--- | :--- | :--- | :--- |
| **人体活动感应** | E53_IS1 热释电红外 | `GPIO_7` | J1 第 7 脚 | 数字输入，内部上拉，上升沿硬件中断 |
| **本地报警蜂鸣** | E53_IS1 无源蜂鸣器 | `GPIO_8` | J1 第 8 脚 | PWM 输出，复用为 `PWM1`（4kHz / 50% 占空比） |
| **门窗磁检测** | 干簧管传感器组件 | `GPIO_13` | J1 第 5 脚 | 数字输入，开内部上拉（闭合=0，断开=1） |
| **紧急求助按键** | 板载 F1 按键 (SOS) | `GPIO_11` | J1 第 15 脚 | 数字输入，开内部上拉，按下接地（低电平有效） |
| **现场消警复位** | 板载 F2 按键 (RESET)| `GPIO_12` | J1 第 2 脚 | 数字输入，开内部上拉，按下接地（低电平有效） |
| **系统运行/警报**| 板载黄色高亮 LED | `GPIO_2` | J1 第 6 脚 | 数字输出，正常慢闪（心跳），告警急促爆闪 |
| **调试与遥测串口**| CH340 板载串口芯片 | `GPIO_3` / `GPIO_4` | J1 第 20/17 脚 | UART0，波特率 115200 8N1，输出标准 JSON 遥测流 |

## 四、 软件架构与核心功能算法实现

### 4.1 嵌入式多任务调度与并发架构
设备端基于 CMSIS-RTOS v2 标准接口构建多任务并发机制，主控核心划分为三大协同运行逻辑：
1. **高频去抖与响应逻辑 (50ms 周期)**：持续对 F1/F2 按键与干簧管进行滑动窗口多次采样滤波，消除物理抖动带来的毛刺干扰；实时驱动声光蜂鸣器与 LED 状态机；
2. **事件驱动中断逻辑 (异步触发)**：E53_IS1 红外传感器输出上升沿直接触发硬件 ISR 回调，瞬时刷新“最后活动时间戳”，并将今日累计活动计数加一；
3. **秒级决策与遥测调度逻辑 (1000ms 周期)**：驱动环境微气候算法，综合判断多传感器阈值，仲裁当前告警等级，通过串口与网络输出格式化 JSON 遥测数据帧。

### 4.2 核心安全事件判定算法

#### 4.2.1 长时间未活动（跌倒/昏迷）双阈值判定模型
$$T_{\text{idle}} = t_{\text{current}} - t_{\text{last\_motion}}$$
系统实时累计老人未被红外感应检测到的静止时长 $T_{\text{idle}}$：
- 当 $T_{\text{idle}} < \text{THRESHOLD}_{\text{warning}}$：系统判定老人处于正常坐卧休息，安全指示灯维持绿色心跳闪烁；
- 当 $T_{\text{idle}} \ge \text{THRESHOLD}_{\text{critical}}$（答辩演示配置为 30 秒，实际可调为 2~4 小时）：系统判定老人极可能发生意外摔倒、心脑血管突发疾病导致无法移动，立即触发 `ALERT_TYPE_NO_MOTION` 严重告警，本地声光拉响连环啸叫，并向北向平台推送一级跌倒救援广播。

#### 4.2.2 门窗出入与长开未关异常算法
干簧管传感器实时检测门窗状态：
- 当干簧管检测到电平断开（高电平），启动开门计时器 $T_{\text{door}}$；
- 若 $T_{\text{door}} \ge 15\text{s}$（常开未关阈值），系统判定老人可能外出遗忘关门，或遭遇外人撬门入侵，触发 `ALERT_TYPE_DOOR_TIMEOUT` 预警，蜂鸣器发出“双蜂鸣”提示音，提醒老人或邻居关好防盗门。

#### 4.2.3 紧急求助 SOS 抢占式仲裁机制
老人主动按下随身或床头 F1 按键瞬间，状态机直接抢占所有低优先级事件，直接进入最高危救援模式（`ALERT_LEVEL_CRITICAL`），蜂鸣器以 400ms 急促周期爆闪连鸣；按动 F2 键或由家属在北向平台下发消警指令，方可恢复常态，确保生命呼救万无一失。

## 五、 事件闭环管理工作台与大数据规律分析

### 5.1 事件闭环管理业务流
赛题明确强调“事件闭环管理”要求。本系统设计了标准的闭环台账引擎：
```
[传感器异常触发] ──► [本地声光报警 + 串口/网络遥测推送]
                             │
                             ▼
                   [北向系统弹出预警处置窗口]
                             │
                             ▼
                 [子女/网格员上门核实与电话排查]
                             │
                             ▼
              [录入处置结论 (老人平安/送医/误报)]
                             │
                             ▼
                   [生成安全电子台账并消警归档]
```
处置结论支持一键导出为标准 CSV/电子表格台账，支持长期跟踪老人健康与生活状态。

### 5.2 老人生活健康与活动规律可视化
系统根据全天候感知数据，构建了老人日常生活行为画像：
1. **24 小时活跃时段分布柱状图**：清晰描摹老人的起夜频率、晨起时间、做饭时段与就寝作息。若出现深更半夜活动频次异常升高，提示老人可能出现失眠、认知障碍或夜间身体不适；
2. **7 日活动趋势与健康评分模型**：实时比对今日总活动量与历史均值。如系统测算得出“今日活动频次较昨日下降 22%”，系统自动标黄并提示监护人重点问候，及早预防潜在慢性疾病恶化。

## 七、 创新亮点与竞赛竞争力总结

1. **极致软硬件协同设计**：攻克了单 E53 扩展插座与 GPIO 引脚冲突难题，巧妙结合板载按键与外引干簧管，在极简硬件条件下实现了赛题要求的全部核心功能；
2. **无感守护与绝对隐私保障**：全系统无需老人佩戴任何电子元件，杜绝漏充漏戴；全流程采用开关量与物理特征传感，不采集任何视频图像，在卧室与卫生间提供全天候无死角隐私安全守护；
3. **真实可用的事件闭环机制**：突破了传统物联网“只报不管”的弊端，深度契合社区基层网格治理与家庭适老监护实战需求，形成了“预警-排查-处置-归档”的完整业务台账闭环；
4. **自主可控的开源鸿蒙底座**：从底层 LiteOS-M 嵌入式内核到北向应用呈现，全面依托国产自主可控技术体系，响应国家信息技术应用创新战略。
