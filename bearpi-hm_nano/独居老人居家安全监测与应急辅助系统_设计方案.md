# 独居老人居家安全监测与应急辅助系统 —— 设计方案

## 一、 项目背景与设计目标

### 1.1 项目背景
随着我国人口老龄化进程加速，高龄空巢、独居老人的比例持续攀升。独居老人由于身体机能衰退，极易在日常生活中发生突发性疾病、意外跌倒、夜间迷途走失或室内用电用火安全事故。然而，由于独居缺乏常态化照料，老人在遭遇突发意外时往往无法自主报警或及时呼救，造成“黄金抢救时间延误”，极易酿成严重人身安全后果。

传统基于穿戴式设备（如智能手环、跌倒手表）的监护方案，由于需要老人频繁充电、主动佩戴，极易因老人遗忘、排斥佩戴而造成监护“窗口期”失效；传统的室内网络摄像头方案又存在严重的隐私侵犯隐患，在卫生间、卧室等高危跌倒场所难以部署；此外，厨房燃气泄漏与电气阴燃引发的火险也是独居老人居家的一大隐患。由于老年人通常伴有听力弱化或视力模糊，仅靠简单的蜂鸣器蜂鸣，老人往往难以快速识别发生的是何种险情。

### 1.2 设计目标
针对上述社会痛点，本项目基于开源鸿蒙（OpenHarmony）轻量系统与北向分布式应用架构，研发了一套**“非感官接触式、高隐私保护、视听双模适老交互、软硬件南北向一体化”**的独居老人居家安全监测与应急辅助系统。系统旨在实现：
1. **多维度被动感知与环境火险监测**：融合热释电红外人体感应、干簧管门窗磁传感器、微气候温湿度传感器及烟雾/可燃气体传感器，实现老人日常活动轨迹、门窗出入状态以及厨房用火用气安全的隐形守护，免除穿戴负担；
2. **抢占式主动呼救与多模态适老化联动**：提供便携式紧急 SOS 按键，结合现场无源蜂鸣器、爆闪状态指示灯与**智能语音合成播报模块（SYN6288 TTS）**，在异常发生瞬间拉响现场警报并主动进行清晰的中文语音语音播报（如“检测到燃气泄漏，请立即开窗并撤离”），消除认知障碍；
3. **北向全景监控与智能健康规律分析**：构建老人日常生活规律图谱，自动统计分析 24 小时活跃时段分布及 7 日活动趋势，辅助子女及早研判老人身体衰退征兆；
4. **事件闭环管理工作台**：预警发生后，子女与社区网格员可一键确认、排查、反馈处置结论，形成电子化居家安全日志台账，实现安全隐患全周期闭环追踪。

## 三、 硬件选型与引脚电气设计

### 3.1 核心硬件选型
- **核心主控开发板**：小熊派 BearPi-HM Nano。搭载海思 Hi3861V100 高度集成 2.4GHz Wi-Fi SoC 芯片，集成 32 位 RISC-V 微控制器，最大主频 160MHz，内置 352KB SRAM 与 288KB ROM，支持硬件浮点与安全引擎，专为物联网与 OpenHarmony 轻量设备开发设计。
- **人体活动感应扩展板**：BearPi E53_IS1。集成数字热释电红外传感器与高分贝无源蜂鸣器，有效感应角度达 100°，感应距离达 3~5 米，检测到有人走动时输出高电平脉冲。
- **环境温湿度传感器**：BearPi E53_IA1 板载工业级 SHT30 I²C 传感器（集成微气候动态平滑补偿算法），测温精度达 ±0.2℃，测湿精度达 ±2%RH。
- **烟雾与可燃气体传感器**：BearPi E53_SF1。板载 MQ-2 高灵敏度气敏传感元件，对液化气、丙烷、氢气、天然气以及火灾烟雾具备优异响应特性，输出线性模拟电压信号。
- **门窗磁传感器**：高灵敏度磁敏干簧管组件。采用磁性接近吸合原理，门窗关闭时磁铁吸合触点导通接地；门窗打开时触点断开，利用芯片内部上拉输出高电平，具有无机械磨损、零待机功耗、高可靠等特性。
- **适老化中文语音合成模块**：SYN6288 语音模块。支持 GB2312/GBK 汉字文本转清晰自然的人声播报，自带背景音合成与音频功放驱动，提供直观、无障碍的险情语音提醒。
- **紧急求助输入**：板载微动轻触按键 F1 与消警按键 F2，自带硬件抗冲击设计。

### 3.2 硬件引脚分配与防冲突设计
针对 BearPi-HM Nano 的 15 个 GPIO 资源与外设电气特性，经过系统性排查与信号复用分配，彻底避免了总线冲突与管脚争用，管脚分配如下：

| 功能模块 | 对应外设 / 器件 | 硬件 GPIO 映射 | 对应 J1 座子物理位置与丝印 | 信号方向与配置属性 |
| :--- | :--- | :--- | :--- | :--- |
| **人体活动感应** | E53_IS1 热释电红外 | `GPIO_7` | J1 左列第 7 孔（丝印 `GPIO2`） | 数字输入，内部上拉，上升沿硬件中断 |
| **本地报警蜂鸣** | E53_IS1 无源蜂鸣器 | `GPIO_8` | J1 左列第 8 孔（丝印 `GPIO3`） | PWM 输出，复用为 `PWM1`（4kHz / 50% 占空比） |
| **微气候温湿 SDA** | E53_IA1 (SHT30 SDA) | `GPIO_0` | J1 左列第 10 孔（丝印 `IIC_SDA`） | I²C1 数据线，配置内部弱上拉，标准速率 100kHz |
| **微气候温湿 SCL** | E53_IA1 (SHT30 SCL) | `GPIO_1` | J1 左列第 9 孔（丝印 `IIC_SCL`） | I²C1 时钟线，配置内部弱上拉，标准速率 100kHz |
| **烟雾燃气检测 AO** | E53_SF1 (MQ-2 模拟量)| `GPIO_13` | J1 左列第 5 孔（丝印 `ADC`） | 模拟输入，复用为 `ADC Channel 6` (`HI_ADC_CHANNEL_6`) |
| **门窗磁检测** | 磁敏干簧管组件 | `GPIO_10` | J1 左列第 1 孔（丝印 `SPI_SCK`） | 数字输入，内部上拉（闭合接地=0，断开=1），与烟雾 SF1 零冲突 |
| **适老化语音播报** | SYN6288 语音模块 RXD | `GPIO_6` | J1 右列第 3 孔（丝印 `UART_TX`） | 串口输出，复用为 `UART1_TXD`（波特率 9600 8N1） |
| **语音忙状态/反馈** | SYN6288 BUSY / TXD | `GPIO_5` | J1 右列第 2 孔（丝印 `UART_RX`） | 串口输入/数字输入，复用为 `UART1_RXD` 或查询播报状态 |
| **紧急求助按键** | 板载 F1 按键 (SOS) | `GPIO_11` | 板载独立微动开关 | 数字输入，内部上拉，按下接地（低电平有效） |
| **现场消警复位** | 板载 F2 按键 (RESET)| `GPIO_12` | 板载独立微动开关 | 数字输入，内部上拉，按下接地（低电平有效） |
| **系统运行/警报**| 板载黄色高亮 LED | `GPIO_2` | 板载发光二极管 | 数字输出，正常慢闪（心跳），告警急促爆闪 |
| **调试与遥测串口**| CH340 板载串口芯片 | `GPIO_3` / `GPIO_4`| J1 右列第 1/4 孔（丝印 `GPIO4/5`）| UART0，波特率 115200 8N1，USB 输出标准 JSON 遥测流 |

### 3.3 电源供电与电气接线注意事项
1. **E53_SF1 传感器供电**：MQ-2 传感器内部包含加热线圈，用于维持气敏半导体的反应温度（约 200℃）。其工作电流通常在 120mA~160mA 之间，**必须接主板 5V 供电引脚**，若接 3.3V 会导致预热不充分、读数灵敏度大幅衰减；
2. **SYN6288 语音模块供电**：模块板载自带音频放大芯片（如 LM4871），为保证驱动喇叭时人声音量洪亮、无爆音杂音，**推荐接主板 5V 供电**；模块信号引脚兼容 3.3V TTL 电平，可直接与 Hi3861 的 `GPIO_6` (`UART1_TXD`) 互联；
3. **共地保障**：所有外接扩展板与模块的 GND 必须与主控底板的 GND 统一共地，消除地电位差引起的模拟采样漂移与串口通信误码。

## 四、 软件架构与核心功能算法实现

### 4.1 嵌入式多任务调度与并发架构
设备端基于 CMSIS-RTOS v2 标准接口构建多任务并发机制，主控核心划分为四大协同运行逻辑：
1. **高频去抖与声光状态机逻辑 (50ms 周期)**：持续对 F1/F2 按键与干簧管进行滑动窗口采样滤波，消除物理机械抖动毛刺；实时驱动声光蜂鸣器与 LED 状态机；
2. **事件驱动中断响应逻辑 (异步触发)**：E53_IS1 红外传感器输出上升沿直接触发硬件 ISR 回调，瞬时刷新“最后活动时间戳”，并将今日累计活动计数加一；
3. **秒级决策与遥测调度逻辑 (1000ms 周期)**：驱动环境微气候与烟雾燃气 ADC 采样算法，综合判定多传感器阈值，仲裁当前告警等级，通过串口与网络输出格式化 JSON 遥测数据帧；
4. **异步语音播报任务逻辑 (消息队列驱动)**：构建低内存消耗的语音播报事件队列，接收告警触发时的语音文本，格式化为 SYN6288 专用二进制协议帧，通过 UART1 异步推流，避免主控循环阻塞。

### 4.2 核心安全事件判定与联动算法

#### 4.2.1 长时间未活动（跌倒/昏迷）双阈值判定模型
$$T_{\text{idle}} = t_{\text{current}} - t_{\text{last\_motion}}$$
系统实时累计老人未被红外感应检测到的静止时长 $T_{\text{idle}}$：
- 当 $T_{\text{idle}} < \text{THRESHOLD}_{\text{warning}}$：系统判定老人处于正常坐卧休息，安全指示灯维持慢闪心跳；
- 当 $T_{\text{idle}} \ge \text{THRESHOLD}_{\text{critical}}$（答辩演示配置为 30 秒，实际可调为 2~4 小时）：系统判定老人极可能发生意外摔倒、心脑血管突发疾病导致无法移动，立即触发 `ALERT_TYPE_NO_MOTION` 严重告警，本地声光拉响连环啸叫，语音播报“长时间未检测到活动，请确认老人安全”，并向北向平台推送一级跌倒救援广播。

#### 4.2.2 门窗出入与长开未关异常算法
干簧管传感器实时检测门窗状态：
- 当干簧管检测到电平断开（高电平），启动开门计时器 $T_{\text{door}}$；
- 若 $T_{\text{door}} \ge 15\text{s}$（常开未关阈值），系统判定老人可能外出遗忘关门，或遭遇外人撬门入侵，触发 `ALERT_TYPE_DOOR_TIMEOUT` 预警，蜂鸣器发出“双蜂鸣”提示音，语音模块播报“门窗长时间未关，请及时确认”，提醒老人或邻居关好防盗门。

#### 4.2.3 紧急求助 SOS 抢占式仲裁机制
老人主动按下随身或床头 F1 按键瞬间，状态机直接抢占所有低优先级事件，直接进入最高危救援模式（`ALERT_LEVEL_CRITICAL`），蜂鸣器以 400ms 急促周期爆闪连鸣，语音播报“正在呼救，已向家属与网格员发送紧急求助”，北向平台即刻全屏红色警报；按动 F2 键或由家属在北向平台下发消警指令，方可恢复常态，确保生命呼救万无一失。

#### 4.2.4 室内烟雾与可燃气体火险监测算法
$$V_{\text{gas}} = \frac{D_{\text{raw}} \times 1.8 \times 4}{4096.0}$$
Hi3861 通过 `hi_adc_read` 对 `HI_ADC_CHANNEL_6`（`GPIO_13`）进行周期性模拟量采集。系统采用滑动窗口平滑滤波滤除瞬时电气尖峰：
- 当采集电压或等效浓度超过预警阈值时（$V_{\text{gas}} \ge V_{\text{gas\_warn}}$），系统判定存在轻微烟雾或燃气初起泄漏，触发二级黄色预警；
- 当浓度急剧上升突破危险阈值时（$V_{\text{gas}} \ge V_{\text{gas\_danger}}$），立即升级为最高级生命财产险情（L3 严重告警），声光连鸣不绝，语音模块反复循环播报“检测到燃气或烟雾浓度超标，请立即开窗通风并迅速撤离”，同时网关与北向应用零延迟触发应急预案。

#### 4.2.5 适老化智能语音合成播报（SYN6288 TTS）
针对老人视力下降、无法辨识屏幕细小文字的问题，系统内置中文语音播报引擎。播报数据帧遵循 SYN6288 标准协议：
`[0xFD] [Length_H] [Length_L] [0x01] [0x01 | Music<<4] [GBK_Text] [ECC]`
- **语音播报优先级调度**：紧急 SOS > 燃气烟雾火险 > 跌倒未活动 > 门窗长开 > 温湿度异常；
- **防频发抑制与播放保护**：高优先级事件可打断低优先级播报，相同类型的播报引入时间间隔抑制，避免语音喋喋不休造成老人情绪恐慌。

## 五、 事件闭环管理工作台与大数据规律分析

### 5.1 事件闭环管理业务流
系统严格践行“事件闭环管理”设计思想，涵盖设备现场自救、家属远程排查与社区网格化联动：
```
[传感器异常触发] ──► [本地高分贝声光 + 中文语音播报 + 串口/网络遥测推送]
                             │
                             ▼
                   [北向系统弹出预警处置窗口]
                             │
                             ▼
                 [子女/网格员上门核实与电话排查]
                             │
                             ▼
              [录入处置结论 (老人平安/送医/火险排除/误报)]
                             │
                             ▼
                   [生成安全电子台账并消警归档]
```
处置结论支持一键导出为标准 CSV/电子表格台账，支持长期跟踪老人健康与生活状态。

### 5.2 老人生活健康与活动规律可视化
系统根据全天候感知数据，构建了老人日常生活行为画像：
1. **24 小时活跃时段分布柱状图**：清晰描摹老人的起夜频率、晨起时间、做饭时段与就寝作息。若出现深更半夜活动频次异常升高，提示老人可能出现失眠、认知障碍或夜间身体不适；
2. **7 日活动趋势与健康评分模型**：实时比对今日总活动量与历史均值。如系统测算得出“今日活动频次较昨日下降 22%”，系统自动标黄并提示监护人重点问候，及早预防潜在慢性疾病恶化。

## 七、 创新亮点与竞赛竞争力总结

1. **多外设极致软硬件协同**：在小熊派 BearPi-HM Nano 紧凑的 GPIO 资源下，通过精细化管脚复用，完美协同了 I²C、UART、ADC、PWM、GPIO 中断及板载按键，实现了红外、门磁、温湿、烟雾燃气、TTS 语音播报五大功能模块的无冲突并行运行；
2. **适老化多模态无障碍交互**：突破了传统设备仅依赖刺耳蜂鸣的局限，专门引入 SYN6288 汉字语音合成引擎，发生险情时直接说出“人话”，指导视听机能衰退的老人快速避险，极具人文关怀温度；
3. **无感守护与绝对隐私保障**：全系统无需老人佩戴任何电子元件，杜绝漏充漏戴；全流程采用开关量、环境量与物理特征传感，不采集任何视频图像，在卧室与卫生间提供全天候无死角隐私安全守护；
4. **真实可用的事件闭环机制**：突破了传统物联网“只报不管”的弊端，深度契合社区基层网格治理与家庭适老监护实战需求，形成了“预警-排查-处置-归档”的完整业务台账闭环；
5. **自主可控的开源鸿蒙底座**：从底层 LiteOS-M 嵌入式内核到北向应用呈现，全面依托国产自主可控技术体系，响应国家信息技术应用创新战略。
