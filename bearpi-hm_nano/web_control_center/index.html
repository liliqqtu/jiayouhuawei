1. 为什么选项里没有“CM7”？
“CM7”是数据线的品牌型号（如绿联/品胜线材），而 Windows 操作系统中所有外接硬件的通信通道统一以 COM 端口 命名（如 COM3, COM4, COM7 等），设备名称一般显示为 USB-SERIAL CH340 (COMx)。


2. 弹出的窗口里找不到小熊派开发板？
• 请确认是否为“纯充电线”：很多手机充电线内部只有供电线，没有数据线芯。如果电脑发出叮咚声但提示“未知 USB 设备”，说明该线无法传数据，请更换一条支持数据传输的 Type-C 线。
• 检查是否安装 CH340 驱动：小熊派主板使用 CH340 芯片，若未安装驱动电脑不会分配端口。驱动安装包在：
D:\DevEco\resources\toolset\DevTools_Hi3861V100\1.0.0\usb_serial_driver\CH341SER.EXE


3. 如果不想折腾接线，如何录制视频或答辩？
系统已内置【全真交互模拟器】，直接点击页面上的“有人活动”、“切换门窗”、“模拟跌倒”等按钮，声光告警、闭环工单、健康图表全流程功能一应俱全！
