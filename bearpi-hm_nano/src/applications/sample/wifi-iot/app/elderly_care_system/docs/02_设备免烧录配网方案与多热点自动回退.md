# 独居老人居家安全监测系统 —— 免烧录配网方案与工程演进

## 一、 为什么老是需要重新烧录 Wi-Fi？

在当前代码中：
```c
// elderly_care_config.h
#define CFG_WIFI_SSID       "xin Pro"
#define CFG_WIFI_PASSWORD   "kdxbryvq35uxd4r"
```
由于 Wi-Fi 账号密码直接写死在头文件中：
- 一旦您把板子带到**办公室/学校实验室**，或者开启**手机热点**；
- 或者给其他测试人员、用户使用时，由于别人家里的 Wi-Fi 名字不同，板子就会一直处于离线报错状态；
- 普通用户不可能懂得安装 DevEco 工具链去改 C 语言代码并重新烧录。

## 二、 解决路径：三级递进配网方案

针对不同的开发阶段，我们规划了三级配网演进策略：

```
[第一阶段：开发与答辩神器] ──► 智能多热点轮询回退 (Multi-AP Auto-Fallback)
                               (无需重编译，家里/热点/实验室走到哪自动连到哪)
                                       │
                                       ▼
[第二阶段：标准消费级产品] ──► SoftAP 手机网页配网 (手机连板子热点配置)
                               (米家/天猫精灵同款配网交互，体验极佳)
                                       │
                                       ▼
[第三阶段：鸿蒙超级终端]   ──► 一碰连 / 碰一碰 NFC 极速配网
                               (搭载 OpenHarmony 软总线能力)
```

---

### 阶段 1：智能多热点自动轮询（开发调试立竿见影，10 分钟实现 ⭐⭐⭐⭐⭐）

#### 设计原理
在固件中定义一个**“常用已知热点候选列表”**（比如：家里路由器、手机热点、实验室 Wi-Fi）。
小熊派开机时，先扫描周围空气中的 Wi-Fi 信号：
- 看到哪个在列表里，就自动连哪个！
- 如果家里 Wi-Fi 连不上，您只要手机打开“个人热点”，小熊派立刻在 3 秒内自动切换到手机热点上！
- **彻底告别换一个环境就重新烧录一次固件的痛苦！**

#### 数据结构示例
```c
typedef struct {
    const char *ssid;
    const char *psk;
} wifi_candidate_t;

static const wifi_candidate_t g_candidate_list[] = {
    { "xin Pro",       "kdxbryvq35uxd4r" }, // 环境 A：常用日常 Wi-Fi
    { "iPhone 15 Pro", "12345678"        }, // 环境 B：随身手机热点 (答辩路演利器)
    { "Lab_WiFi_5G",   "openharmony2026" }, // 环境 C：实验室/教室 Wi-Fi
};
```

### 阶段 2：SoftAP 网页配网（标准智能家居方案 ⭐⭐⭐⭐⭐）

#### 用户交互体验（完全不需要接触任何代码）
1. **首次开机或长按 F2 按键 5 秒**：
   - 小熊派蜂鸣器“哔哔”两声，进入配网模式；
   - 小熊派自身发出一个开放式 Wi-Fi 热点，名为 `ElderlyCare_Setup_xxxx`。
2. **手机端操作**：
   - 用户的手机搜索并连接这个热点 `ElderlyCare_Setup_xxxx`；
   - 手机会自动弹出一个网页（或者在浏览器输入 `192.168.1.1`）；
   - 网页上自动列出搜索到的附近 Wi-Fi 列表，用户点击自家 Wi-Fi，输入密码，点击【保存并连接】。
3. **开发板端处理**：
   - 小熊派内置的 HTTP 守护服务（`src/third_party/httpd`）解析接收到的账号密码；
   - 调用海思 Hi3861 系统的 **KV 存储接口（Flash 非易失性保存）**：
     ```c
     UtilsSetValue("wifi_ssid", new_ssid, strlen(new_ssid));
     UtilsSetValue("wifi_psk", new_psk, strlen(new_psk));
     ```
   - 开发板自动重启，以后每次开机直接从 Flash 读取，即使停电也不会丢失！

## 三、 手机 App 如何实现“零配置”对齐？

### 传统做法 vs 现代化物联网做法对比
- **落后的传统做法**：
  手机 App 界面上留着输入框：`[请输入服务器 IP: 10.179.139.87]`、`[请输入端口: 9999]`。
  只要内网 IP 变了，手机就变成砖头。
- **现代化物联网做法**：
  手机 App 安装后，只让用户填一个东西：**设备序列号（Device ID）**，或者直接点【扫一扫】，扫描贴在小熊派外壳上的二维码！
  - 二维码内容：`{"dev_id": "Care_6891", "model": "BearPi_ElderlyCare"}`
  - 手机 App 扫描后，在后台自动订阅 MQTT 主题：
    `elderly_care/Care_6891/alarm`
  - 只要开发板联网上报，不管它在哪个省、连的是谁家的宽带，手机都能随时随地接收并推送！
