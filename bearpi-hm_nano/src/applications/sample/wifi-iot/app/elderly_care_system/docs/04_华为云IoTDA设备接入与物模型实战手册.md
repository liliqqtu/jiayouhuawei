# 独居老人居家安全监测系统 —— 华为云 IoTDA 设备接入与物模型实战手册

> **赛题背景**：2026年（第三届）河南省高等学校信息技术应用创新大赛 —— 赛题四：独居老人居家安全监测与应急辅助系统  
> **核心架构**：小熊派 BearPi-HM Nano (OpenHarmony LiteOS-M) ➔ 华为云 IoTDA ➔ 开源鸿蒙 APP (API 12 / ArkTS)

## 一、 华为云 IoTDA 平台端配置流程（5分钟完成）

### 1.1 登录与开通设备接入服务
1. 打开浏览器访问 [华为云官网](https://www.huaweicloud.com/)，登录账号并完成实名认证；
2. 搜索进入 **“设备接入 IoTDA”**（控制台地址：北京四 `cn-north-4` 或 华南广州 `cn-south-1`）；
3. 如果首次使用，免费开通“标准版”或使用控制台的基础版（每个月有 **100 万条免费消息**，比赛演示绰绰有余）。

---

### 1.2 创建产品与导入物模型（Profile）

1. 在左侧菜单点击 **【产品】 ➔ 【创建产品】**：
   - **所属资源空间**：默认空间
   - **产品名称**：`ElderlyCare_Monitor`
   - **协议类型**：`MQTT`
   - **数据格式**：`JSON`
   - **厂商名称**：`OpenHarmony_Team`
   - **设备类型**：`ElderlyCare`
2. 点击刚创建的产品，进入 **【模型定义】** 页面；
3. 选择 **【自定义模型】** 或直接上传导入如下物模型：

#### 核心服务 (Service) 定义清单

##### 服务 1：`ElderlyCare`（核心健康与环境感知服务）
| 属性名称 (Property) | 属性标识符 (Key) | 数据类型 | 取值范围 | 读写权限 | 业务说明 |
| :--- | :--- | :--- | :--- | :---: | :--- |
| **紧急求助状态** | `SosActive` | `int` | `0`=正常, `1`=求助中 | 读 | F1 或无线遥控触发 |
| **求助触发来源** | `SosSource` | `int` | `0`=无, `1`=F1, `2`=无线遥控 | 读 | 区分床头/随身遥控 |
| **人体活动检测** | `MotionActive` | `int` | `0`=无人, `1`=有人 | 读 | E53_IS1 红外瞬时状态 |
| **距上次活动秒数** | `SecondsSinceMotion` | `int` | `0 ~ 86400` | 读 | 未移动超时跌倒判定 |
| **今日累计活动次** | `MotionEventsToday` | `int` | `0 ~ 9999` | 读 | 24小时活跃度健康图谱 |
| **门窗磁开关状态** | `DoorOpen` | `int` | `0`=闭合, `1`=开启 | 读 | 干簧管出入监测 |
| **当前室内温度** | `Temperature` | `decimal` | `-20.0 ~ 60.0` | 读 | SHT30 微气候温度 (℃) |
| **当前室内湿度** | `Humidity` | `decimal` | `0.0 ~ 100.0` | 读 | SHT30 相对湿度 (%RH) |
| **烟雾燃气电压** | `SmokeVoltage` | `decimal` | `0.0 ~ 3.3` | 读 | E53_SF1 MQ-2 采样模拟量 |
| **综合告警等级** | `AlertLevel` | `int` | `0`=正常, `1`=提示, `2`=预警, `3`=严重 | 读 | 本地状态机仲裁等级 |
| **告警触发原因** | `AlertType` | `int` | `0`=无, `1`=SOS, `2`=未移动, `3`=门未关, `4`=高温, `5`=低温, `6`=烟雾 | 读 | 驱动手机精准弹窗 |
| **语音播报音量** | `VoiceVolume` | `int` | `0 ~ 16` | 读写 | SYN6288 功放播报音量 |

##### 服务 2：命令下发 (Commands)
| 命令名称 (Command) | 下发参数 | 参数类型 | 作用说明 |
| :--- | :--- | :--- | :--- |
| **`ResetAlert`** | `operator` | `string` | 远程一键消警（家属/网格员确认后解除声光） |
| **`SetVoiceVolume`** | `volume` | `int` (0~16) | 远程调节开发板语音提示音量 |

### 1.3 注册设备并获取鉴权三元组

1. 在左侧菜单点击 **【设备】 ➔ 【所有设备】 ➔ 【注册设备】**；
2. **所属产品**：选择刚刚创建的 `ElderlyCare_Monitor`；
3. **设备标识码 (NodeId)**：输入自定义编码（例如 `ElderlyCare_001`）；
4. **设备名称**：`独居老人小熊派主控_001`；
5. **设备密钥 (Secret)**：设置一个强密码（例如 `Huawei123456!`）并**务必复制保存**；
6. 创建成功后，华为云会提供设备的连接三元组信息：
   - **`DeviceId`（设备ID）**：例如 `6114182f2cce4f0286ff45f9_ElderlyCare_001`
   - **`Secret`（密钥）**：`Huawei123456!`
7. **生成 MQTT ClientId / Username / Password**：
   - 在华为云 IoTDA 页面中，使用内置的 **【MQTT 连接参数生成器】**（或开源小工具）；
   - 输入 `DeviceId` 和 `Secret`，点击一键生成：
     - **ClientId**：`6114182f2cce4f0286ff45f9_ElderlyCare_001_0_0_2026110600`
     - **Username**：`6114182f2cce4f0286ff45f9_ElderlyCare_001`
     - **Password**：一串 64 位的 HMAC-SHA256 加密密文

## 二、 南向小熊派代码对接逻辑

在小熊派代码库中，官方原本就封装了原生的 `oc_mqtt` 驱动（位于 `vendor/bearpi/bearpi_hm_nano/demo/D6_iot_cloud_oc`），我们只需将其核心接口桥接至 `elderly_care_system`：

```c
// 1. 初始化华为云设备信息
device_info_init(CLIENT_ID, USERNAME, PASSWORD);

// 2. 连接华为云 IoTDA (MQTT 1883)
oc_mqtt_init();

// 3. 注册接收云端下发控制指令的回调函数 (如远程消警)
oc_set_cmd_rsp_cb(OnCloudCommandReceived);

// 4. 定时或告警时上报属性至华为云设备影子
oc_mqtt_profile_propertyreport(DEVICE_ID, &service);
```
