## 二、 空间几何参数与数学物理建模

### 2.1 核心空间几何参数

| 参数名称 | 符号 | 标准指标 | 物理意义与环境边界 |
| :--- | :---: | :---: | :--- |
| **水平探测视角** | $\theta_H$ | **$100^\circ \sim 110^\circ$** | 水平扇形扩散角，正前方为主轴，左右各扩散 $50^\circ \sim 55^\circ$ |
| **垂直探测视角** | $\theta_V$ | **$70^\circ \sim 80^\circ$** | 垂直俯仰扩散角，分为远区光束、中区光束与下倾近区光束 |
| **推荐壁挂高度** | $H$ | **$1.8\,\text{m} \sim 2.0\,\text{m}$** | 最佳安装高度，防老人遮挡碰撞，兼顾坐立与地面跌倒 |
| **下倾俯仰倾角** | $\alpha$ | **$10^\circ \sim 15^\circ$** | 传感器向下低头倾角，用于压缩消除墙脚近身盲区 |
| **核心探测半径** | $R_1$ | **$1.0\,\text{m} \sim 3.0\,\text{m}$** | **高灵敏核心区**：极微小的肢体挪动、起身均能 100% 触发 |
| **边缘探测极限** | $R_{\max}$ | **$5.0\,\text{m}$** | **极限有效区**：需要躯干整体走动横切光束方可稳定触发 |
| **下盲区半径** | $D_{\text{blind}}$ | **$0.4\,\text{m} \sim 0.8\,\text{m}$** | 传感器垂直正下方由光学死角导致的盲区距离 |

---

### 2.2 几何覆盖面数学公式

#### 1. 远端地面水平最大扫描跨度 ($W_{\max}$)
在极限距离 $R_{\max} = 5\,\text{m}$ 处，水平扇面的横向跨度为：
$$W_{\max} = 2 \times R_{\max} \times \sin\left(\frac{\theta_H}{2}\right) = 2 \times 5.0 \times \sin(50^\circ) \approx 7.66\,\text{米}$$
> **结论**：单颗 E53_IS1 安装在房间一侧墙壁中央，即可横向扫过 **7.6 米** 的室内开阔面，足以完全覆盖常规家庭的卧室或客厅主活动动线。

#### 2. 地面有效监控投影面积 ($S_{\text{cover}}$)
水平扇形在地面的投影面积计算为：
$$S_{\text{cover}} = \frac{\theta_H}{360^\circ} \times \pi R_{\max}^2 = \frac{100^\circ}{360^\circ} \times \pi \times (5.0)^2 \approx 21.8\,\text{m}^2$$
> **结论**：有效监控空间达到 **21.8 平方米**，完美匹配独居老人主卧（通常 15~20 平方米）的全面积无死角监控。

#### 3. 墙脚感应下盲区计算 ($D_{\text{blind}}$)
若传感器水平正放（俯角 $\alpha = 0^\circ$），其垂直最下边缘光束与垂直墙面的夹角为 $90^\circ - \frac{\theta_V}{2} = 50^\circ$。
盲区半径为：
$$D_{\text{blind}} = H \times \tan(50^\circ) = 1.8 \times 1.19 \approx 2.14\,\text{米} \quad (\text{死角过大！})$$
若我们将传感器**向下倾斜 $\alpha = 15^\circ$**：
最下边缘光束与垂直地面的夹角缩小，触地距离变为：
$$D_{\text{blind}} = \frac{H}{\tan\left(\frac{\theta_V}{2} + \alpha\right)} = \frac{1.8}{\tan(40^\circ + 15^\circ)} = \frac{1.8}{\tan(55^\circ)} \approx \frac{1.8}{1.428} \approx 1.26\,\text{米}$$
如果俯角增加到 $20^\circ$，盲区将进一步压缩至 **$0.7\,\text{米}$** 以内！

## 三、 菲涅尔透镜（Fresnel Lens）光学多扇区切割机理

板载正中央白色半球盖（菲涅尔透镜）并不是普通的防护罩，而是**光学多焦聚光镜面阵列**：

```
                    【菲涅尔透镜多光束扇区剖面】
                     
                              [E53_IS1 传感器]
                                  /  |  \
                                 /   |   \
                                /    |    \
                        光束1  /  光束2 \  光束3
                              /      |     \
                             /       |      \
     ──────┬────────────────┴────────┴───────┴─────────────────┬─────
           │ 盲区 │ 敏感带1 │ 盲区 │ 敏感带2 │ 盲区 │ 敏感带3 │ 盲区 │
     ──────┴───────────────────────────────────────────────────┴─────
                               老人走动方向 ───► (横穿)
```

1. **明暗交替的“光阑效应”**：
   透镜将 $100^\circ \times 80^\circ$ 的空间分割成由 **3 层、共 24~32 个独立感应光束**构成的三维立体光网。
2. **为什么横向走动最灵敏？**
   - 老人横穿房间时，身体会从“光束1 ➔ 盲区 ➔ 光束2 ➔ 盲区 ➔ 光束3”快速切换；
   - 热释电元件检测到的红外光斑能量发生急剧正负跳变，输出高达数百毫伏的交变差分电压，触发电路瞬间翻转 `GPIO_7` 为高电平。
3. **为什么纵向走来较迟钝？**
   - 若老人笔直迎着传感器走来，人体一直处于同一根主光束内部，光斑大小变化缓慢，温差微分电荷产生迟缓，灵敏度显著低于横切运动。

## 四、 适老化工程部署最佳实践

为保证独居老人居家监测既不误报、又不漏报，建议采取以下布设规范：

```
┌─────────────────────────────────────────────────────────────────┐
│                           老 人 卧 室                           │
│                                                                 │
│   [防盗门] ──(门磁检测)                                          │
│      │                                                          │
│      ▼                                                          │
│   ┌───────────────────────────┐         ┌───────────────────┐   │
│   │     主 起 居 动 线         │         │      老 人 床     │   │
│   │   (老人上下床、喝水走动)   │         │  (夜间正常静卧)   │   │
│   │                           │         │                   │   │
│   │      ↔ 横切探测主光束     │         └───────────────────┘   │
│   └─────────────▲─────────────┘                   │             │
│                 │                                 ▼             │
│                 │ 100° 水平扇面覆盖        [无线 SOS 呼叫键]    │
│                 │                                               │
│       ┌─────────────────┐                                       │
│       │ E53_IS1 传感器  │ (安装在侧向墙面 1.8m 处，下倾 15°)     │
│       └─────────────────┘                                       │
└─────────────────────────────────────────────────────────────────┘
```

1. **安装高度**：壁挂于距地面 **$1.8\,\text{m} \sim 2.0\,\text{m}$** 的侧墙上。
2. **俯角配置**：保持 **$15^\circ$ 下俯角**，确保老人即使在床沿或墙角滑倒在地，也在下部光束的捕获范围内。
3. **动线垂直布设**：将传感器安装在**老人下床走往门口或卫生间的必经路线侧面**，使老人走动轨迹与红外扇面形成垂直横切关系，灵敏度达到最高峰。
4. **避让干扰源**：
   - 远离暖气片、电热水壶上方；
   - 避免正对太阳直射的窗户或空调摆叶吹风口，防止空气对流引起伪温度梯度跳变。
