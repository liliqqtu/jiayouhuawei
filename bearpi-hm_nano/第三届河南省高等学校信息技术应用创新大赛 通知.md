# 河南省高等学校计算机教育研究会关于举办2026年（第三届）河南省高等学校信息技术应用创新大赛的通知

## 二、竞赛内容

本次大赛以“鸿蒙筑基，创新赋能”为主题，聚焦基础开发能力培养与技术创新拓展，兼顾赛事包容性与区分度，为在校大学生提供展示自身专业能力的舞台。参赛队伍需基于 OpenHarmony（开源鸿蒙）进行应用开发或设备开发，基于物联网云平台进行设备管理，以开源鸿蒙 APP 为控制端。使用开源鸿蒙硬件开发环境、DevEco Studio 应用开发环境。共有 4 个赛题，每支参赛队伍只能从中选择 1 个赛题参赛。

# 附件1：开源鸿蒙大赛参赛方案

## 一、比赛方案

1. **开发环境**：统一使用 DevEco Studio 开发工具，基于 OpenHarmony 系统进行开发，要求 API 版本 12 及以上；
2. **硬件要求**：纯北向应用类赛题使用鸿蒙手机、平板或模拟器即可完成开发，无需额外采购硬件；南北结合类赛题需使用开源鸿蒙开发板及配套传感器模组，不强制要求多套硬件、高阶通信模组；
3. **数据存储**：可采用本地离线存储方案，云端存储、多设备数据同步等功能仅作为创新加分项，不做强制要求。

### 赛题四：独居老人居家安全监测与应急辅助系统（南北结合软硬件开发类）

#### 背景与目标
随着社会老龄化程度加深，独居老人群体日益庞大。老人在家中突发意外（跌倒、突发疾病、燃气泄漏等）时往往无法及时求助，极易酿成严重后果。本赛题要求基于 OpenHarmony 开发一套轻量化居家安全监测与应急辅助系统，通过部署基础传感设备，实时监测老人居家状态与环境安全，在异常情况下自动预警并协助老人快速求助，为独居老人的居家安全提供技术保障。

#### 主要功能
1. **南向数据采集与控制**：在老人家中部署红外人体传感器（监测老人活动轨迹，判断是否长时间无移动）、门窗磁传感器（监测门窗开关状态，辅助判断老人是否外出或异常出入）、温湿度传感器（监测室内环境舒适度），老人随身佩戴紧急求助按钮（无线便携式），开发板实时采集各传感器数据，通过基础阈值算法识别异常状态。
2. **本地声光预警与自助求助**：当监测到异常情况（如长时间未检测到人体活动，疑似跌倒或昏迷；温湿度异常，疑似空调/暖气故障）时，自动触发现场声光报警器，提醒邻居或物业注意；老人也可主动按下随身紧急求助按钮，触发本地声光报警，同时通过语音模块播放预设求助语音（如“我需要帮助”）。
3. **北向数据展示**：子女/监护人手机端应用实时查看家中各传感器状态（人体活动最后触发时间、门窗开关记录、当前温湿度等），展示设备在线状态与电量信息；支持按日期查看老人活动规律报告（如“今日活动频次较昨日下降 20%”）；支持历史预警记录查询与详情查看。
4. **事件闭环管理**：预警发生后，子女/监护人通过应用确认预警信息，填写处置结果（如“已联系社区网格员上门查看”“老人一切正常，误报”），形成居家安全日志，便于长期跟踪老人生活状态。
5. **数据统计分析**：自动统计老人日常活动时段分布、每日活动频次趋势，生成周/月报告，帮助子女发现老人生活规律变化（如活动量持续下降可能预示健康问题），辅助判断老人身体状况变化。

#### 创新拓展功能
1. **多维度监测**：新增烟雾传感器（监测火灾）和燃气传感器（监测燃气泄漏），综合研判居家安全风险，实现多维度安全守护。
2. **星闪自组网**：采用星闪技术实现家中多个传感器与开发板之间的低功耗自组网，解决家中 Wi-Fi 覆盖不全的问题，确保各房间传感器数据稳定回传。
3. **远程告警推送**：搭载 4G 通信模组，预警信息实时上传云端，通过应用推送至子女/监护人手机（即使子女不在老人身边也能第一时间获知异常）。
4. **多终端协同**：预警信息同步推送至子女、社区网格员、物业值班人员等多台手机，确保老人求助后快速得到响应。

## 二、参赛作品内容

### 1. 提交作品内容
参赛团队需提交以下三类材料，所有材料内容中**均不得出现参赛团队、指导老师、院校等相关信息**，确保评审公平公正。
- **(1) 设计方案**：需提交详细版 Word 文档（`*.docx` 格式），内容应包含作品设计思路、功能实现逻辑、技术架构、软硬件选型、测试结果等，正文统一采用宋体、小四号字体，1.5 倍行距。
- **(2) 演示视频**：需提交全方位展示作品各项功能的演示视频，视频格式为 `mp4`，文件大小不超过 100MB，播放时长控制在 5 分钟以内，视频需清晰展示作品的操作流程、功能效果。
- **(3) PPT 演示文稿**：需提交图文并茂的 PPT 文稿，内容完整、简明扼要，重点展示作品的设计亮点、功能实现、创新点等，文稿对应的讲解时长控制在 10 分钟以内。
